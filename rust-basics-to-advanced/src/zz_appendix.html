용어

용어뜻
크레이트(crate)컴파일 단위. 라이브러리 하나 또는 실행 파일 하나. crates.io에 배포되는 패키지 단위이기도 하다.
소유권(ownership)모든 값은 소유자 하나를 가지며, 소유자가 스코프를 벗어나면 값이 해제된다는 규칙.
이동(move)소유권을 다른 변수로 넘기는 것. 원래 이름은 이후 사용할 수 없다.
Copy / Clone비트 복사로 충분한 타입의 암묵적 복사 / 명시적 깊은 복사.
빌림(borrow)소유권을 넘기지 않고 참조를 만드는 것. &T는 공유, &mut T는 배타.
빌림 검사기"공유 XOR 변경"과 "참조는 원래 값보다 오래 살 수 없다"를 검사하는 컴파일러 단계.
NLLnon-lexical lifetimes. 빌림이 스코프 끝이 아니라 마지막 사용 지점에서 끝난다는 규칙.
라이프타임('a)참조가 유효한 구간의 이름. 참조들 사이의 관계를 시그니처에 적는 컴파일 타임 정보.
슬라이스 / 팻 포인터연속 메모리 일부에 대한 참조. (포인터, 길이) 두 워드. dyn Trait 참조는 (포인터, vtable).
트레잇(trait)타입이 구현할 수 있는 동작의 계약. 인터페이스, 연산자, 마커(Send/Sync) 모두 트레잇.
단형화(monomorphization)제네릭 코드를 사용된 구체 타입마다 별도로 컴파일하는 것. 정적 디스패치.
dyn 호환(object safety)트레잇을 dyn Trait로 쓸 수 있는 조건. 제네릭 메서드, Self 반환 등이 있으면 불가.
고아 규칙트레잇 구현은 트레잇이나 타입 중 하나가 내 크레이트 것일 때만 가능.
내부 가변성&T를 통해서도 내용을 바꿀 수 있게 하는 것(Cell, RefCell, Mutex, 원자 타입).
Send / Sync다른 스레드로 옮겨도 안전 / 여러 스레드가 공유 참조를 가져도 안전.
Future / Wakerpoll로 진행시키는 미완료 계산 / 기다리던 일이 생기면 작업을 다시 스케줄하게 하는 핸들.
Pin값이 메모리에서 이동하지 않음을 보장하는 포인터 래퍼. 자기 참조 future에 필요.
UB정의되지 않은 동작. safe Rust에서는 발생하지 않으며, unsafe 코드가 약속을 어길 때 생긴다.
MiriMIR 인터프리터. 실행하며 UB(정렬, 범위, 별칭 규칙 위반 등)를 탐지한다.
niche타입이 쓰지 않는 비트 패턴. Option 등이 태그 없이 이를 이용해 크기를 줄인다.
타입 상태(typestate)상태를 타입 매개변수로 표현해 잘못된 상태 전이를 컴파일 오류로 만드는 패턴.
에디션하위 호환을 깨지 않고 문법을 다듬는 단위(2015/2018/2021/2024). 크레이트마다 선택.
MSRVminimum supported Rust version. 크레이트가 지원을 약속하는 가장 오래된 컴파일러 버전.
부록 B

참고 자료와 다음 단계

공식 문서 (무료)

  • The Rust Programming Language ("the book"): 공식 입문서. 이 책의 Part I–II와 겹치며 더 자세한 설명이 있다.
  • Rust by Example: 짧은 예제 위주로 문법을 훑는다.
  • 표준 라이브러리 문서: 각 타입의 메서드 목록과 예제. 실무에서 가장 자주 여는 페이지.
  • The Rust Reference: 언어 명세에 가장 가까운 문서.
  • The Edition Guide: 2024 에디션 변경점(unsafe extern, RPIT 캡처 규칙 등).
  • The Rustonomicon: unsafe Rust의 규칙과 함정. 14장의 다음 단계.
  • Asynchronous Programming in Rust: 13장의 다음 단계.
  • The Embedded Rust Book: no_std, PAC/HAL, 인터럽트, 메모리 맵 I/O.
  • Rust API Guidelines: 라이브러리 API 설계 체크리스트.
  • Clippy lints: 모든 린트와 이유.
  • Comprehensive Rust: Google Android 팀의 4일 과정 교재. Android·베어메탈·동시성 특화 과정 포함.
  • Rust Atomics and Locks (Mara Bos): 원자 연산·메모리 순서·락 구현. 온라인 무료 공개.

책

  • Jon Gjengset, Rust for Rustaceans (No Starch Press, 2021): 중급에서 고급으로 가는 설계 감각. 이 책 Part III–IV의 다음 단계.
  • Jim Blandy, Jason Orendorff, Leonora Tindall, Programming Rust (2nd ed., O'Reilly, 2021): 시스템 프로그래머 관점의 두꺼운 레퍼런스.
  • Tim McNamara, Rust in Action (Manning, 2021): 시스템 프로그래밍 프로젝트 중심.

생태계와 도구

  • releases.rs / Rust 릴리스 공지: 6주마다 나오는 안정판의 변경 사항.
  • Tokio 튜토리얼, Embassy: 서버용과 임베디드용 async 런타임.
  • ros2_rust (rclrs): ROS 2의 Rust 클라이언트 라이브러리.
  • Ferrocene: ISO 26262·IEC 61508 인증을 받은 Rust 툴체인. 안전 필수 시스템용.
  • Rust for Linux: 리눅스 커널의 Rust 지원 현황과 드라이버.
  • Miri, cargo-fuzz, loom, proptest: 14·16장의 검증 도구.

이 책의 실행 엔진

  • Rust Playground: Rust 프로젝트가 운영하는 공식 온라인 실행 환경. 이 책의 기본 엔진이며 Miri도 제공한다.
  • Compiler Explorer: 코드가 어떤 어셈블리로 바뀌는지 볼 수 있다. 9·16장의 "반복자는 비용이 0인가?"를 직접 확인할 때 좋다.
  • Wandbox: 여러 언어·버전의 컴파일러를 제공하는 온라인 실행 서비스.
