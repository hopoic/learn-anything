Part IV · 고급 엔지니어의 Rust — 17장

실전: 미니 로봇 메시지 버스

이 장을 마치면: 직렬 링크에서 들어오는 바이트 스트림을 프레임 단위로 복원하는 상태 기계 파서, 타입이 있는 메시지와 오류, 토픽별 구독과 스레드 노드로 이루어진 작은 메시지 버스를 직접 읽고 고칠 수 있고, 그 설계 결정 하나하나가 앞 장들의 어떤 개념에서 왔는지 짚을 수 있습니다.

마지막 장입니다. 로봇 소프트웨어에서 가장 흔한 구조 하나를 처음부터 만듭니다. MCU가 UART로 IMU·오도메트리·비상 정지 메시지를 보내고, 리눅스 쪽 데몬이 그것을 파싱해 여러 노드(안전 감시, 위치 추정)에 나눠 주는 구조입니다. ROS 2의 아주 작은 친척이라고 생각하면 됩니다.

//! minibus: a tiny robot message bus. //! serial bytes -> streaming parser -> typed messages -> topic routing -> node threads use std::collections::HashMap; use std::fmt; use std::sync::atomic::{AtomicU64, Ordering::Relaxed}; use std::sync::mpsc::{sync_channel, Receiver, SyncSender, TrySendError}; use std::sync::Arc; use std::thread::{self, JoinHandle}; // ---------------------------------------------------------------- wire format // [0xA5][topic: u8][len: u16 LE][payload; len][crc8 over topic..=payload] const SYNC: u8 = 0xA5; const MAX_PAYLOAD: usize = 64; fn crc8(data: &[u8]) -> u8 { data.iter().fold(0u8, |mut crc, &b| { crc ^= b; for _ in 0..8 { crc = if crc & 0x80 != 0 { (crc << 1) ^ 0x07 } else { crc << 1 }; } crc }) } #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)] #[repr(u8)] enum Topic { Imu = 1, Odom = 2, Estop = 3 } impl TryFrom for Topic { type Error = DecodeError; fn try_from(b: u8) -> Result { match b { 1 => Ok(Topic::Imu), 2 => Ok(Topic::Odom), 3 => Ok(Topic::Estop), other => Err(DecodeError::UnknownTopic(other)), } } } #[derive(Debug, Clone, PartialEq)] enum Message { Imu { ax: f32, ay: f32, az: f32 }, Odom { x: f32, y: f32, theta: f32 }, Estop { reason: u8 }, } #[derive(Debug, PartialEq)] enum DecodeError { UnknownTopic(u8), BadLength { topic: Topic, len: usize }, TooLong(usize), BadCrc { expected: u8, got: u8 }, } impl fmt::Display for DecodeError { fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result { match self { DecodeError::UnknownTopic(t) => write!(f, "unknown topic {t}"), DecodeError::BadLength { topic, len } => write!(f, "{topic:?} payload has wrong length {len}"), DecodeError::TooLong(n) => write!(f, "frame length {n} exceeds {MAX_PAYLOAD}"), DecodeError::BadCrc { expected, got } => write!(f, "crc mismatch (expected {expected:#04x}, got {got:#04x})"), } } } impl std::error::Error for DecodeError {} fn f32s(p: &[u8]) -> [f32; N] { std::array::from_fn(|i| f32::from_le_bytes(p[i * 4..i * 4 + 4].try_into().unwrap())) } impl Message { fn topic(&self) -> Topic { match self { Message::Imu { .. } => Topic::Imu, Message::Odom { .. } => Topic::Odom, Message::Estop { .. } => Topic::Estop, } } fn payload(&self) -> Vec { match *self { Message::Imu { ax, ay, az } => [ax, ay, az].iter().flat_map(|v| v.to_le_bytes()).collect(), Message::Odom { x, y, theta } => [x, y, theta].iter().flat_map(|v| v.to_le_bytes()).collect(), Message::Estop { reason } => vec![reason], } } /// A complete frame, ready for the wire. fn encode(&self) -> Vec { let payload = self.payload(); let mut frame = Vec::with_capacity(payload.len() + 5); frame.push(SYNC); frame.push(self.topic() as u8); frame.extend_from_slice(&(payload.len() as u16).to_le_bytes()); frame.extend_from_slice(&payload); frame.push(crc8(&frame[1..])); frame } fn decode(topic: Topic, p: &[u8]) -> Result { let bad = || DecodeError::BadLength { topic, len: p.len() }; Ok(match topic { Topic::Imu if p.len() == 12 => { let [ax, ay, az] = f32s::<3>(p); Message::Imu { ax, ay, az } } Topic::Odom if p.len() == 12 => { let [x, y, theta] = f32s::<3>(p); Message::Odom { x, y, theta } } Topic::Estop if p.len() == 1 => Message::Estop { reason: p[0] }, _ => return Err(bad()), }) } } // ---------------------------------------------------------------- streaming parser /// Byte-at-a-time state machine: works no matter how the serial driver chunks the data. #[derive(Debug, Clone, Copy)] enum State { Sync, Topic, LenLo, LenHi { lo: u8 }, Payload, Crc } struct FrameParser { state: State, topic: u8, len: usize, buf: Vec } impl FrameParser { fn new() -> Self { FrameParser { state: State::Sync, topic: 0, len: 0, buf: Vec::with_capacity(MAX_PAYLOAD) } } /// Feed one byte; returns Some(..) when a frame finished (good or bad). fn push(&mut self, b: u8) -> Option> { use State::*; match self.state { Sync => if b == SYNC { self.state = Topic; }, // skip garbage until SYNC Topic => { self.topic = b; self.state = LenLo; } LenLo => self.state = LenHi { lo: b }, LenHi { lo } => { self.len = u16::from_le_bytes([lo, b]) as usize; self.buf.clear(); if self.len > MAX_PAYLOAD { self.state = Sync; return Some(Err(DecodeError::TooLong(self.len))); } self.state = if self.len == 0 { Crc } else { Payload }; } Payload => { self.buf.push(b); if self.buf.len() == self.len { self.state = Crc; } } Crc => { self.state = Sync; let mut hdr = vec![self.topic]; hdr.extend_from_slice(&(self.len as u16).to_le_bytes()); hdr.extend_from_slice(&self.buf); let expected = crc8(&hdr); if expected != b { return Some(Err(DecodeError::BadCrc { expected, got: b })); } // `crate::Topic`: inside this fn, `Topic` alone means State::Topic (glob import above) return Some(crate::Topic::try_from(self.topic).and_then(|t| Message::decode(t, &self.buf))); } } None } } // ---------------------------------------------------------------- bus #[derive(Default)] struct Stats { published: AtomicU64, delivered: AtomicU64, dropped: AtomicU64, bad_frames: AtomicU64 } type Sub = (&'static str, SyncSender>); struct Bus { subs: HashMap>, stats: Arc } impl Bus { fn new() -> Self { Bus { subs: HashMap::new(), stats: Arc::new(Stats::default()) } } /// Bounded queue per subscriber: a slow node can never block the publisher. fn subscribe(&mut self, node: &'static str, topics: &[Topic], depth: usize) -> Receiver> { let (tx, rx) = sync_channel(depth); for &t in topics { self.subs.entry(t).or_default().push((node, tx.clone())); } rx } fn publish(&self, msg: Message) { self.stats.published.fetch_add(1, Relaxed); let msg = Arc::new(msg); // one allocation, shared by all subscribers for (_node, tx) in self.subs.get(&msg.topic()).into_iter().flatten() { match tx.try_send(Arc::clone(&msg)) { Ok(()) => { self.stats.delivered.fetch_add(1, Relaxed); } Err(TrySendError::Full(_)) => { self.stats.dropped.fetch_add(1, Relaxed); } // best-effort QoS Err(TrySendError::Disconnected(_)) => {} } } } } // ---------------------------------------------------------------- nodes trait Node: Send + 'static { fn name(&self) -> &'static str; fn on_message(&mut self, msg: &Message); fn summary(&self) -> String; } fn spawn_node(mut node: N, rx: Receiver>) -> JoinHandle { thread::Builder::new() .name(node.name().into()) .spawn(move || { for msg in rx { node.on_message(&msg); } // ends when the bus is dropped node.summary() }) .expect("spawn node thread") } struct Safety { estops: Vec, impacts: u32 } impl Node for Safety { fn name(&self) -> &'static str { "safety" } fn on_message(&mut self, msg: &Message) { match *msg { Message::Estop { reason } => self.estops.push(reason), Message::Imu { ax, ay, .. } if (ax * ax + ay * ay).sqrt() > 15.0 => self.impacts += 1, _ => {} } } fn summary(&self) -> String { format!("estops={:?} impacts={}", self.estops, self.impacts) } } struct Odometer { last: Option<(f32, f32)>, distance: f32, samples: u32 } impl Node for Odometer { fn name(&self) -> &'static str { "odometer" } fn on_message(&mut self, msg: &Message) { if let Message::Odom { x, y, .. } = *msg { if let Some((px, py)) = self.last { self.distance += ((x - px).powi(2) + (y - py).powi(2)).sqrt(); } self.last = Some((x, y)); self.samples += 1; } } fn summary(&self) -> String { format!("samples={} distance={:.2} m", self.samples, self.distance) } } // ---------------------------------------------------------------- main: simulate a serial link fn main() { // 1) Self-checks: every message survives an encode/decode round trip. let samples = [ Message::Imu { ax: 0.1, ay: -9.8, az: 0.2 }, Message::Odom { x: 1.0, y: 2.0, theta: 0.5 }, Message::Estop { reason: 7 }, ]; for m in &samples { let mut p = FrameParser::new(); let out: Vec<_> = m.encode().into_iter().filter_map(|b| p.push(b)).collect(); assert_eq!(out, vec![Ok(m.clone())], "round trip failed for {m:?}"); } println!("self-check: round trip ok for {} message types", samples.len()); // 2) Build a byte stream: odometry along a 3-4-5 path, an impact, one corrupted frame, junk, an e-stop. let mut wire: Vec = vec![0x00, 0x13, 0x37]; // line noise before the first frame for (i, (x, y)) in [(0.0, 0.0), (3.0, 0.0), (3.0, 4.0), (6.0, 8.0)].into_iter().enumerate() { wire.extend(Message::Odom { x, y, theta: i as f32 * 0.1 }.encode()); wire.extend(Message::Imu { ax: 0.2, ay: 9.7, az: 0.0 }.encode()); } wire.extend(Message::Imu { ax: 12.0, ay: 14.0, az: 0.0 }.encode()); // a bump let mut corrupted = Message::Estop { reason: 99 }.encode(); corrupted[4] ^= 0xFF; // flip payload bits: CRC must catch it wire.extend(corrupted); let unknown = [9u8, 1, 0, 0]; // valid CRC, but topic 9 doesn't exist wire.push(SYNC); wire.extend(unknown); wire.push(crc8(&unknown)); wire.extend(Message::Estop { reason: 2 }.encode()); // 3) Wire up the bus and the node threads. let mut bus = Bus::new(); let safety_rx = bus.subscribe("safety", &[Topic::Imu, Topic::Estop], 64); let odo_rx = bus.subscribe("odometer", &[Topic::Odom], 64); let handles = vec![ spawn_node(Safety { estops: vec![], impacts: 0 }, safety_rx), spawn_node(Odometer { last: None, distance: 0.0, samples: 0 }, odo_rx), ]; // 4) Feed the stream in odd-sized chunks, like a UART driver would. let mut parser = FrameParser::new(); for chunk in wire.chunks(7) { for &b in chunk { match parser.push(b) { Some(Ok(msg)) => bus.publish(msg), Some(Err(e)) => { bus.stats.bad_frames.fetch_add(1, Relaxed); println!("rejected frame: {e}"); } None => {} } } } // 5) Shut down: dropping the bus drops every Sender, so every node loop ends. let stats = Arc::clone(&bus.stats); drop(bus); for h in handles { let name = h.thread().name().unwrap_or("?").to_string(); println!("{name:>9}: {}", h.join().expect("node panicked")); } println!("published={} delivered={} dropped={} bad_frames={}", stats.published.load(Relaxed), stats.delivered.load(Relaxed), stats.dropped.load(Relaxed), stats.bad_frames.load(Relaxed)); }

출력을 하나씩 대조해 보겠습니다.

  • self-check: 세 메시지 타입 모두 encode → push를 거쳐 원래 값으로 돌아옵니다. assert_eq!는 Result와 Message가 PartialEq를 derive했기 때문에 쓸 수 있습니다.
  • rejected frame 두 줄: 페이로드를 뒤집은 비상 정지 프레임은 CRC가 잡았고, 토픽 9 프레임은 CRC는 맞지만 TryFrom이 거부했습니다. 그 뒤의 정상 프레임은 파서가 다시 동기화해 받아 냅니다. 맨 앞의 잡음 3바이트는 SYNC를 찾는 동안 조용히 버려졌습니다.
  • safety: 손상된 비상 정지(reason 99)는 들어오지 않았고 정상인 reason 2만 들어왔습니다. 가속도 크기가 15를 넘은 충격이 한 번 감지됐습니다.
  • odometer: (0,0)→(3,0)→(3,4)→(6,8)의 거리 3 + 4 + 5 = 12 m.
  • stats: 발행 10건이 모두 전달되었고, 큐가 넘치지 않아 버린 메시지는 0건입니다.

확장 과제

코드를 편집해 직접 해 보세요. 위로 갈수록 쉽고, 아래로 갈수록 실무 고급 엔지니어의 일에 가깝습니다.

  1. QoS 실험: odometer의 큐 깊이를 2로 줄이고, on_message에 thread::sleep(Duration::from_millis(5))를 넣어 느린 노드를 만드세요. dropped가 늘어나는 것을 확인하고, "가장 오래된 것 버리기"(keep-last) 정책을 구현해 보세요. (힌트: 노드 쪽에서 try_iter()로 비우고 마지막 것만 처리)
  2. 새 토픽 추가: Battery { volts: f32, percent: u8 }를 추가하세요. match의 완전성 검사가 고쳐야 할 곳을 모두 알려 줍니다(5장).
  3. 제로 카피 파서: 지금 파서는 페이로드를 Vec에 모읍니다. 버퍼 전체가 메모리에 있는 경우를 위해 fn parse_all<'a>(buf: &'a [u8]) -> impl Iterator<Item = Result<Frame<'a>, DecodeError>>를 만들어 보세요. Frame<'a>는 페이로드를 &'a [u8]로 빌립니다(10장).
  4. no_std 이식: 파서와 Message를 별도 크레이트로 빼서 #![no_std]로 만드세요. Vec 대신 15장의 const 제네릭 버퍼를 쓰면 MCU 쪽 송신 코드와 같은 크레이트를 공유할 수 있습니다.
  5. async 버전: tokio의 tokio-serial과 mpsc로 바꾸고, 노드를 tokio::spawn 작업으로 만드세요. 블로킹 지점이 어디였는지 13장의 함정 목록과 대조해 보세요.
  6. 검증: proptest로 "임의의 메시지를 encode하고 임의 위치에서 쪼개 넣어도 같은 메시지가 나온다"를, cargo fuzz로 "어떤 바이트열에도 파서가 panic하지 않는다"를 확인하세요(16장).

최종 체크리스트와 다음 단계

이 책을 마친 당신이 할 수 있어야 하는 것
  • 컴파일 오류 메시지를 보고 소유권·빌림·라이프타임 중 무엇의 문제인지 바로 짚는다.
  • 데이터 구조를 설계할 때 "누가 소유하는가"부터 그린다. Rc<RefCell>은 마지막 수단이다.
  • 오류를 열거형으로 설계하고, 라이브러리와 애플리케이션의 오류 전략을 구분한다.
  • 제네릭/dyn/열거형 중 다형성 방식을 비용과 함께 고른다.
  • 스레드·채널·락·원자·async 중 동시성 도구를 문제에 맞게 고르고, 교착과 취소 안전성을 따진다.
  • unsafe를 작은 safe API 뒤에 숨기고 SAFETY 근거와 Miri로 검증한다.
  • 타입 상태·newtype으로 잘못된 사용을 컴파일 오류로 만든다.
  • CI 게이트(fmt, clippy, test, miri, audit)와 측정 기반 최적화를 습관으로 갖는다.
L1코드가 컴파일되게 만들 수 있다. clone과 unwrap이 많다.
L2빌림으로 설계하고, Result와 반복자로 관용적인 코드를 쓴다. (이 책의 Part II)
L3라이프타임·트레잇·동시성으로 라이브러리 API를 설계한다. 다른 사람이 쓰기 쉬운 크레이트를 만든다. (Part III)
L4unsafe 경계와 타입 수준 설계로 시스템 전체의 불변식을 지킨다. 성능을 측정하고, 팀의 Rust 도입과 리뷰 기준을 이끈다. (Part IV)
L5생태계에 기여한다: 크레이트 유지, RFC 논의, 임베디드/커널/로보틱스 분야의 Rust 기반 구조를 만든다.

다음 단계로는 부록 B의 자료 중 Rust for Rustaceans(설계 감각), Rust Atomics and Locks(동시성 내부), The Rustonomicon(unsafe), 그리고 관심 분야에 따라 The Embedded Rust Book이나 tokio 튜토리얼을 권합니다. 그리고 무엇보다, 지금 C/C++로 유지하는 도구 하나를 골라 Rust로 다시 써 보세요. 컴파일러와의 대화가 가장 빠른 선생입니다.
