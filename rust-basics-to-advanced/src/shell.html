Rust 교본 기초부터 고급 엔지니어까지

Rust=소유권+빌림+타입+트레잇

Rust는 “메모리 안전”과 “C 수준의 성능”을 동시에 약속합니다. 비결은 런타임 검사가 아니라, 소유권·빌림·타입이라는 몇 가지 규칙을 컴파일러가 끝까지 따지는 데 있습니다. 이 책은 그 규칙을 기초부터 하나씩 손으로 확인하고, 라이프타임·동시성·async 내부·unsafe·타입 수준 설계까지 올라가 실무 고급 엔지니어가 쓰는 Rust에 닿도록 만들었습니다. 모든 ▶ 실행 버튼은 진짜 rustc를 돌립니다.

이 책 사용법
  • ▶ 실행: 예제를 컴파일하고 실행합니다. 편집을 누르면 코드를 고칠 수 있고, 편집 중에는 Ctrl/⌘ + Enter로 바로 실행됩니다. 원래대로를 누르면 처음 코드로 돌아갑니다.
  • 컴파일 오류 예제 표시가 붙은 예제는 일부러 컴파일되지 않는 코드입니다. Rust 공부의 절반은 컴파일러 오류 메시지를 읽는 일이니, 실행해서 메시지를 읽고 직접 고쳐 보세요.
  • 실행 엔진(왼쪽 목차 아래): 기본값 자동은 공식 Rust Playground를 먼저 쓰고, 응답이 없으면 Compiler Explorer, Wandbox 순으로 넘어갑니다. 모두 무료 온라인 서비스라 인터넷 연결이 필요하고, 가끔 몇 초에서 수십 초 걸릴 수 있습니다.
  • Miri 버튼이 있는 예제(14장)는 Playground의 Miri 인터프리터로 실행해 정의되지 않은 동작(UB)을 잡아냅니다.
  • 책 전체는 Rust 2024 에디션, 표준 라이브러리만으로 씁니다. 모든 실행 예제는 rustc 1.97(edition 2024)로 컴파일·실행해 검증했습니다.
