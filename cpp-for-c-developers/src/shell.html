C 개발자를 위한 C++ 교본

C++=C+RAII+타입+템플릿

C를 이미 아는 사람에게 C++은 새 언어라기보다 “C로 늘 손으로 하던 일을 컴파일러가 대신 지켜 주는 언어”입니다. 이 책은 그 차이를 하나씩, 직접 컴파일하고 실행해 보며 익히도록 만들었습니다. 모든 ▶ 실행 버튼은 진짜 컴파일러를 돌립니다.

이 책 사용법
  • ▶ 실행: 예제를 컴파일하고 실행합니다. 편집을 누르면 코드를 고칠 수 있고, 편집 중에는 Ctrl/⌘ + Enter로 바로 실행됩니다. 표준 입력이 필요한 예제는 출력 창의 stdin에 값을 넣으세요.
  • 실행 엔진(왼쪽 목차 아래): 기본값 자동은 온라인 GCC(Wandbox → Compiler Explorer)를 먼저 쓰고, 네트워크가 막히면 브라우저 안에서 도는 Clang(WebAssembly)으로 넘어갑니다.
  • 브라우저 내장 엔진은 처음 한 번 약 23MB(압축 전송)를 받은 뒤 캐시하며, 코드가 외부 서버로 나가지 않습니다. 대신 예외(throw/try)와 스레드는 지원하지 않습니다. 10장 예외 예제는 온라인 엔진에서 실행하세요.
