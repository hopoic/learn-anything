STL과 람다

이 장을 마치면: 요구사항에 맞는 표준 컨테이너를 고를 수 있고, 반복자와 알고리즘으로 손으로 짠 루프를 대체할 수 있으며, 람다의 캡처 방식을 구분하고 C++20 레인지로 데이터 처리 파이프라인을 작성할 수 있습니다.

8장의 템플릿이 "타입에 무관한 코드"였다면, STL(표준 템플릿 라이브러리)은 그 기술로 만든 자료구조와 알고리즘 모음입니다. C에서 매번 직접 짜던 연결 리스트·해시 테이블·정렬을 더는 짜지 않아도 됩니다.

컨테이너: 고민되면 vector

컨테이너구조강점C에서의 대응
array<T,N>고정 크기 연속 메모리힙 없음, C 배열과 같은 배치T a[N]
vector<T>가변 크기 연속 메모리임의 접근 O(1), 뒤 추가 분할상환 O(1), 캐시 친화적malloc + realloc 배열
deque<T>블록 배열양 끝 삽입·삭제 O(1)링 버퍼
list<T>이중 연결 리스트중간 삽입 O(1), 반복자 안정성struct list_head
map<K,V> / set<K>균형 이진 트리키 정렬 유지, 조회 O(log n)직접 구현한 트리
unordered_map<K,V>해시 테이블평균 조회 O(1), 순서 없음직접 구현한 해시

교과서의 복잡도만 보면 리스트가 중간 삽입에 유리하지만, 실제 하드웨어에서는 캐시 미스 비용 때문에 수천 개 수준까지는 vector가 거의 항상 이깁니다. 그래서 기본값은 vector이고, 다른 컨테이너는 이유가 있을 때 씁니다.

반복자는 일반화된 포인터다

STL 알고리즘은 컨테이너를 직접 받지 않고 반복자 쌍 [first, last)을 받습니다. 반복자는 포인터를 일반화한 것입니다. *it로 원소를 읽고 ++it로 다음으로 갑니다. 그래서 C 배열의 포인터도 그대로 반복자로 쓸 수 있습니다. 알고리즘과 자료구조가 반복자로 분리되어 있기 때문에 알고리즘 N개 × 컨테이너 M개를 N + M개의 코드로 해결합니다.

#include #include #include #include #include int main() { int raw[] = {5, 3, 9, 1, 7}; // plain C array std::sort(raw, raw + 5); // pointers are iterators std::cout << "sorted C array: "; for (int* p = raw; p != raw + 5; ++p) std::cout << *p << ' '; std::vector v(raw, raw + 5); // construct from an iterator range std::list l(v.rbegin(), v.rend()); // reverse iterators auto it = std::find(l.begin(), l.end(), 7); // same algorithm, different container std::cout << "\nfound 7 in list: " << (it != l.end() ? "yes" : "no"); std::cout << "\nsum = " << std::accumulate(v.begin(), v.end(), 0); auto [mn, mx] = std::minmax_element(v.begin(), v.end()); std::cout << "\nmin = " << *mn << ", max = " << *mx << ", max at index " << (mx - v.begin()) << '\n'; }

알고리즘 + 람다 = 루프 대신 의도

람다는 그 자리에서 정의하는 이름 없는 함수 객체입니다. 문법은 [캡처](매개변수) { 본문 }. 캡처는 바깥 변수를 어떻게 가져올지 정합니다. [x]는 값 복사, [&x]는 참조, [=]/[&]는 쓰인 것 전부. C의 콜백 + void *user_data 조합이 람다 하나로 바뀝니다.

#include #include #include #include struct Reading { std::string sensor; double value; }; int main() { std::vector rs{{"t0", 21.5}, {"t1", 85.2}, {"t2", 19.0}, {"t3", 90.1}, {"t4", 22.3}}; const double limit = 80.0; // count_if + lambda capturing 'limit' by value auto hot = std::count_if(rs.begin(), rs.end(), [limit](const Reading& r) { return r.value > limit; }); std::cout << hot << " readings above " << limit << '\n'; // sort by value, descending std::sort(rs.begin(), rs.end(), [](const Reading& a, const Reading& b) { return a.value > b.value; }); // a stateful lambda: captures 'total' by reference double total = 0; std::for_each(rs.begin(), rs.end(), [&total](const Reading& r) { total += r.value; }); // transform into another container std::vector labels(rs.size()); std::transform(rs.begin(), rs.end(), labels.begin(), [](const Reading& r) { return r.sensor + "=" + std::to_string(int(r.value)); }); for (const auto& s : labels) std::cout << s << ' '; std::cout << "\naverage = " << total / rs.size() << '\n'; // C++20: erase all elements matching a predicate in one call std::erase_if(rs, [](const Reading& r) { return r.value < 20.0; }); std::cout << "after erase_if: " << rs.size() << " readings\n"; // a lambda stored in a variable, used like a function auto in_range = [lo = 20.0, hi = 30.0](double x) { return lo <= x && x <= hi; }; std::cout << std::boolalpha << "in_range(25) = " << in_range(25) << '\n'; }
흔한 함정
  • 반복자 무효화: 순회 중에 erase나 push_back을 하면 기존 반복자가 무효가 될 수 있습니다(vector는 재할당 시 전부). 지우면서 순회하지 말고 std::erase_if를 쓰세요.
  • 매달린 캡처: [&] 람다를 저장해 두었다가 지역 변수가 사라진 뒤 호출하면 매달린 참조입니다. 오래 사는 람다는 필요한 것만 값으로 캡처하세요.

C++20 레인지: 파이프라인으로 읽는 데이터 처리

레인지(ranges)는 begin/end 쌍 대신 컨테이너를 통째로 받고, 뷰(view)를 |로 이어 지연 평가 파이프라인을 만듭니다. 셸의 파이프와 비슷하게 읽힙니다. 뷰는 원소를 복사하지 않고, 결과를 실제로 꺼낼 때 계산합니다.

#include #include #include #include int main() { std::vector adc{512, 1023, 0, 700, 300, 950, 128, 880}; namespace views = std::views; auto volts = adc | views::filter([](int raw) { return raw > 256; }) // drop low readings | views::transform([](int raw) { return raw * 3.3 / 1023; }) // scale to volts | views::take(4); // first 4 only for (double v : volts) std::cout << v << " V\n"; std::ranges::sort(adc); // no begin()/end() needed std::cout << "median-ish: " << adc[adc.size() / 2] << '\n'; for (int i : views::iota(0, 5) | views::reverse) std::cout << i << ' '; std::cout << '\n'; }
C 개발자의 눈으로

"STL은 무겁다"는 인상은 대개 디버그 빌드에서 생깁니다. 최적화를 켜면(-O2) 반복자는 포인터로, 람다는 인라인 코드로 녹아 손으로 짠 루프와 같은 기계어가 나오는 경우가 많습니다. 확인하고 싶다면 같은 코드를 Compiler Explorer(godbolt.org)에 붙여 어셈블리를 비교해 보세요.
