복소수와 IQ: 음의 주파수의 정체

이 장을 마치면: 오일러 공식으로 사인파를 회전하는 화살표로 바꿔 생각할 수 있고, 음의 주파수가 무엇인지 설명하며, RF 신호가 I/Q 복소 기저대역으로 표현되는 원리와 복소 샘플링이 실수 샘플링보다 유리한 이유를 말할 수 있습니다.

회전하는 화살표, ejθ

복소수 z = a + jb는 평면 위의 점, 또는 원점에서 그 점까지의 화살표입니다(전기공학에서는 전류 i와 헷갈리지 않게 허수 단위로 j를 씁니다). 같은 화살표를 길이 r와 각도 θ로도 쓸 수 있고, 이 둘을 잇는 것이 오일러 공식입니다.

ejθ = cos θ + j sin θ   ⇒   z = r ejθ = r cos θ + j r sin θ

이 표기의 힘은 곱셈에서 나옵니다. 두 복소수를 곱하면 길이는 곱해지고 각도는 더해집니다. r1ejθ1 · r2ejθ2 = r1r2ej(θ1+θ2). 길이 1짜리 복소수를 곱하는 것은 곧 회전입니다. 신호처리에서 주파수를 옮기는 일(8장), 위상을 보정하는 일(11장)이 전부 이 곱셈 한 번입니다.

곱셈(ac−bd) + j(ad+bc)길이 곱, 각도 합 (실수 곱셈 4번, 덧셈 2번)

이제 각도가 시간에 비례해 늘어나게 해 봅시다. θ = 2πft라면 ej2πft는 1초에 f바퀴씩 반시계 방향으로 도는 화살표입니다. 그렇다면 f가 음수일 때는? 시계 방향으로 돕니다. 음의 주파수란 회전 방향이 반대인 것, 그 이상도 이하도 아닙니다.

실수 코사인은 반대로 도는 두 화살표의 합이다

오일러 공식을 두 번 쓰면 코사인을 복소 지수로 풀 수 있습니다.

cos(2πft) = ej2πft + e−j2πft2

반시계로 도는 반 길이 화살표와 시계로 도는 반 길이 화살표를 더하면, 허수 성분은 서로 상쇄되고 실수축 위에서 왕복하는 점만 남습니다. 그것이 코사인입니다. 그래서 실수 신호의 스펙트럼에는 언제나 +f와 −f에 같은 크기의 선이 짝으로 나타나고, 양쪽 절반이 같은 정보를 중복해서 담습니다. 2장에서 실수 샘플링에 2B가 필요했던 이유, −f와 f가 구분되지 않았던 이유가 이것입니다.

신호 종류

복소 모드에서 f의 부호를 바꾸면 화살표의 회전 방향과 스펙트럼 선의 위치가 함께 바뀝니다. I 파형(파랑)만 보면 +f와 −f가 똑같지만 Q 파형(주황)은 부호가 뒤집힙니다. 실수 모드로 바꾸면 반대로 도는 두 화살표가 나타나고 스펙트럼이 좌우 대칭이 됩니다. 이때는 f의 부호를 바꿔도 아무것도 달라지지 않습니다.

I와 Q: 두 방향에서 봐야 회전이 보인다

돌아가는 화살표를 옆에서만(코사인 투영) 보면 왼쪽으로 도는지 오른쪽으로 도는지 알 수 없습니다. 90° 돌린 위치에서 한 번 더 보면(사인 투영) 방향이 드러납니다. 이 두 투영이 I(In-phase, 동상)와 Q(Quadrature, 직교)입니다.

반송파 주파수 fc에 실린 RF 신호는 진폭과 위상이 천천히 변하는 사인파입니다. 이 변화를 두 개의 기저대역 신호 I(t), Q(t)로 쓰면 다음과 같습니다.

xRF(t) = I(t) cos(2πfct) − Q(t) sin(2πfct) = Re{ s(t) · ej2πfct },   s(t) = I(t) + j Q(t)

s(t)를 복소 기저대역(complex baseband) 신호, 또는 복소 포락선이라고 부릅니다. 반송파는 단지 s(t)를 fc만큼 회전시켜 옮겨 놓은 것일 뿐이고, 정보는 전부 s(t)에 있습니다. 수신기가 할 일은 그 회전을 되돌리는 것입니다.

왜 이렇게 하면 I와 Q가 나올까요? 곱셈의 삼각함수 공식 cosA cosB = ½[cos(A−B) + cos(A+B)]를 쓰면 위쪽 경로는 ½I(t)와 2fc 근처의 성분으로 나뉩니다. LPF가 2fc 성분을 지우면 ½I(t)만 남습니다. 아래쪽도 같은 방식으로 ½Q(t)가 나옵니다. 복소수로 한 줄에 쓰면 더 간단합니다. 수신 신호에 e−j2πfct를 곱해 반송파의 회전을 되감고, 저역통과로 거르면 s(t)가 남습니다. 송신기는 정확히 반대로, s(t)에 e+j2πfct를 곱하고 실수부를 내보냅니다.

복소 샘플링: fs 하나로 대역폭 B = fs를 본다

복소 기저대역 신호에는 +f와 −f를 구분할 정보가 있습니다. 그래서 스펙트럼의 양쪽 절반이 서로 다른 내용을 담을 수 있고, 샘플률 fs로 −fs/2 ~ +fs/2, 즉 폭 fs의 대역을 앨리어싱 없이 볼 수 있습니다. 숫자 개수로 따지면 복소 샘플 하나가 실수 두 개이므로 데이터량은 실수 샘플링과 같지만, 대역을 반송파 주위 양쪽으로 쓸 수 있다는 것이 결정적인 차이입니다.

예를 들어 AD9361의 LO를 2.44 GHz에, 샘플률을 20 MSPS에 두면 2.43–2.45 GHz가 한 번에 보입니다. FFT에서 음의 주파수 칸은 LO보다 낮은 주파수, 양의 칸은 높은 주파수입니다. 이 "LO가 0 Hz가 된다"는 감각이 SDR 작업의 출발점입니다.

import numpy as np fs, N = 1_000_000, 1000 # 1 MSPS, 1 kHz FFT bins n = np.arange(N) f0 = -200_000 # 200 kHz below the LO complex_tone = np.exp(2j * np.pi * f0 / fs * n) # what an IQ receiver delivers real_tone = np.cos(2 * np.pi * f0 / fs * n) # what a single real ADC delivers freqs = np.fft.fftshift(np.fft.fftfreq(N, 1 / fs)) for name, x in (("complex", complex_tone), ("real", real_tone)): X = np.abs(np.fft.fftshift(np.fft.fft(x))) / N peaks = freqs[X > 0.1] print(f"{name:8s} peaks at {peaks / 1e3} kHz, height {X.max():.2f}")
임베디드 엔지니어의 눈으로

메모리에서 IQ 샘플은 정수 두 개짜리 구조체입니다. AD9361의 12비트 ADC 값은 보통 16비트 정수 두 개(I, Q)로 담겨 32비트 워드 하나가 복소 샘플 하나가 되고, DMA와 AXI-Stream도 이 단위로 움직입니다. pyadi-iio는 이것을 numpy 복소 배열로 돌려줍니다. 한 가지 주의할 점은 I와 Q의 비트 위치나 순서, 부호 확장 방식이 인터페이스마다 다를 수 있다는 것입니다. 새 데이터 경로를 만들면 알려진 주파수의 톤을 넣고 스펙트럼 피크가 올바른 부호 쪽에 나타나는지부터 확인하세요. I와 Q가 뒤바뀌면 스펙트럼이 좌우로 뒤집힙니다.

흔한 함정: 현실의 IQ는 완벽하지 않다
  • DC 오프셋: LO가 새어 들어와 스펙트럼 한가운데(0 Hz)에 뾰족한 선이 생깁니다. 관심 신호를 일부러 0 Hz에서 비켜 두는 이유입니다(8장).
  • IQ 불균형: I와 Q 경로의 이득이 조금 다르거나 위상이 정확히 90°가 아니면, +f의 신호가 −f에 희미한 거울상(image)을 만듭니다. AD936x는 이를 줄이는 직교 보정 기능을 내장하고 있고, ADI 문서는 실수 신호만 받을 때는 이 추적 보정을 꺼야 한다고 안내합니다.
핵심 정리
  • ej2πft는 회전하는 화살표다. 음의 주파수는 반대 방향 회전이다.
  • 실수 신호는 ±f 쌍으로만 존재한다. I와 Q를 함께 가져야 방향(부호)이 보인다.
  • RF 신호 = Re{s(t) ej2πfct}. 수신기는 회전을 되감아 s(t)를 꺼낸다.
