Part I · 신호의 언어 — 1장

신호처리의 지도: 수신기는 숫자 공장이다

이 장을 마치면: RF 수신 체인의 블록 이름을 대고 각 블록이 어떤 신호처리 개념인지 말할 수 있으며, dB·dBm·dBFS를 머릿속에서 바로 환산하고, Zynq의 PL과 PS가 체인의 어느 부분을 맡는지 설명할 수 있습니다.

신호는 시간에 따라 변하는 숫자다

신호(signal)는 시간에 따라 변하는 어떤 양입니다. 안테나 단자의 전압, 마이크의 음압, 가속도 센서의 출력이 모두 신호입니다. 신호를 분류하는 축은 두 개입니다. 시간이 연속인가 띄엄띄엄인가, 그리고 값이 연속인가 정해진 단계만 가질 수 있는가.

값이 연속값이 이산 (양자화)
시간 연속아날로그 신호 x(t) — 안테나 전압비교기 출력, PWM
시간 이산이산 시간 신호 x[n] — 수학적 이상형디지털 신호 — ADC가 내놓는 12비트 정수열

이 책에서는 괄호 모양으로 둘을 구분합니다. x(t)는 연속 시간, x[n]은 n번째 샘플입니다. 신호처리 이론의 대부분은 "시간 이산, 값 연속"을 가정하고 전개되고, 값이 이산이라서 생기는 문제(양자화 잡음, 오버플로)는 9장에서 따로 다룹니다. FPGA를 다루는 사람에게 이 구분은 실무적으로 중요합니다. 알고리즘은 실수(real number)로 설계하고, 구현은 정수로 하기 때문입니다.

시스템은 신호를 받아 신호를 내놓는 함수다

필터, 믹서, 증폭기, 복조기처럼 신호를 받아 다른 신호를 내놓는 것을 모두 시스템이라고 부릅니다. 그중 신호처리가 특별히 아끼는 부류가 선형 시불변(LTI, Linear Time-Invariant) 시스템입니다.

  • 선형: 입력을 두 배 하면 출력도 두 배, 두 입력을 더해 넣으면 각각의 출력을 더한 것이 나옵니다. 중첩의 원리가 성립합니다.
  • 시불변: 오늘 넣든 내일 넣든 같은 입력에는 같은 출력이 (그만큼 늦게) 나옵니다. 계수가 시간에 따라 바뀌지 않습니다.

LTI가 중요한 이유는 하나로 요약됩니다. LTI 시스템에 사인파를 넣으면 같은 주파수의 사인파가 나온다. 크기와 위상만 바뀝니다. 그래서 어떤 신호든 사인파들의 합으로 쪼갤 수 있다면(5장의 푸리에 변환), 시스템은 "주파수마다 크기와 위상을 얼마나 바꾸는가"라는 표 하나로 완전히 기술됩니다. 이 표가 주파수 응답이고, 필터 설계(6장)는 이 표를 원하는 모양으로 만드는 일입니다. 반대로 믹서는 일부러 LTI가 아니게 만든 시스템입니다. 주파수를 옮기는 것이 목적이니까요(8장).

이 책 전체가 다루는 것은 아래 그림의 왼쪽 끝에서 오른쪽 끝까지 신호가 흘러가는 길입니다. 기준 하드웨어는 ADALM-PLUTO(PlutoSDR)로 잡았습니다. AD9363 트랜시버 하나와 Zynq Z-7010이 들어 있는, USB로 전원을 받는 교육용 SDR이라 가장 적은 비용으로 이 책의 모든 개념을 실제 전파로 확인할 수 있습니다.

신호처리 체인은 처리량이 고정된 데이터 파이프라인입니다. 샘플률은 처리량(throughput)이고, 필터 탭 수는 샘플당 연산량이며, 데시메이션은 다음 단계로 넘기는 데이터율을 줄이는 압축입니다. FPGA에서는 "클록마다 샘플 하나가 들어온다"가 기본 계약이고, 그 계약을 지키는 한 지연(latency)은 늘어나도 괜찮습니다. 반대로 PS 쪽 소프트웨어는 샘플이 아니라 버퍼와 패킷 단위로 생각합니다. 이 경계를 어디에 긋느냐가 9장의 주제입니다.

dB 감각: 신호처리의 공용 단위

RF와 신호처리에서는 거의 모든 크기를 데시벨로 말합니다. 곱셈이 덧셈이 되고, 10−12 같은 숫자가 −120처럼 다룰 만한 숫자가 되기 때문입니다. 규칙은 단 하나입니다. 전력의 비는 10 log10, 진폭(전압)의 비는 20 log10. 전력은 진폭의 제곱이므로 두 식은 같은 dB 값을 냅니다.

dB = 10 log10 P2P1 = 20 log10 A2A1
외워 둘 값전력 비진폭 비
+3 dB약 2배약 1.41배
+6 dB약 4배약 2배 (ADC 1비트 = 약 6 dB)
+10 dB10배약 3.16배
+20 dB100배10배
−40 dB1/10,0001/100 (EVM 1%)

dB는 원래 비율이라 단위가 없습니다. 기준을 붙이면 절대량이 됩니다.

  • dBm: 1 mW 기준 전력. 0 dBm = 1 mW, 30 dBm = 1 W, −100 dBm = 0.1 pW. 수신기 감도와 송신 출력이 이 단위입니다.
  • dBFS: ADC 풀스케일(full scale) 기준. 0 dBFS가 ADC가 표현할 수 있는 최대 크기이고, 디지털 영역의 신호는 전부 음수 dBFS로 표시됩니다. 스펙트럼 분석(5장)과 고정소수점(9장)의 기본 단위입니다.
  • dBc: 반송파(carrier) 기준. "스퓨리어스가 −60 dBc"는 주 신호보다 60 dB 낮다는 뜻입니다.

체인 전체의 이득은 각 단의 dB를 더하면 됩니다. LNA +15 dB, 믹서 −6 dB, 기저대역 증폭 +40 dB라면 합계 +49 dB입니다. −90 dBm의 신호가 −41 dBm으로 ADC에 도착합니다. 이 계산이 암산으로 되기 시작하면 RF 문서가 읽히기 시작합니다.

import numpy as np def db_power(ratio): return 10 * np.log10(ratio) def db_amp(ratio): return 20 * np.log10(ratio) def dbm_to_mw(dbm): return 10 ** (dbm / 10) print(f"power x2 -> {db_power(2):5.2f} dB") print(f"amplitude x2 -> {db_amp(2):5.2f} dB") print(f"-90 dBm -> {dbm_to_mw(-90):.1e} mW") # Cascade gain is a sum in dB: LNA, mixer loss, baseband amplifier print(f"chain gain -> {15 - 6 + 40} dB, so -90 dBm arrives at {-90 + 15 - 6 + 40} dBm")

핵심 정리
  • LTI 시스템은 사인파를 사인파로 바꾼다. 그래서 주파수 응답 하나로 완전히 기술된다.
  • 수신 체인은 "주파수를 내리고 → 샘플링하고 → 거르고 → 샘플률을 줄이고 → 동기를 맞춰 → 판정"하는 파이프라인이다.
  • dB는 전력이면 10 log, 진폭이면 20 log. dBm은 1 mW 기준, dBFS는 ADC 풀스케일 기준이다.

다음 장에서는 이 체인의 한가운데, 연속 신호가 숫자열로 바뀌는 순간인 샘플링을 들여다봅니다. 거기서 신호처리 전체를 관통하는 이상한 성질 하나, "디지털 세계에서 주파수는 한 바퀴 돌면 제자리로 온다"를 만나게 됩니다.
