디지털 변조와 펄스 성형

이 장을 마치면: 비트를 BPSK·QPSK·16-QAM 심볼로 매핑하고, 펄스 성형과 정합 필터가 대역폭과 ISI를 어떻게 다루는지 설명하며, Es/N0·Eb/N0·EVM·BER 사이를 환산하고, 성상도의 모양만 보고 수신기의 문제를 진단할 수 있습니다.

비트를 평면 위의 점으로

3장에서 IQ 신호 하나는 매 순간 복소 평면의 한 점이었습니다. 디지털 변조는 이 평면에 미리 정해 둔 점 몇 개를 찍어 두고, 보내려는 비트에 따라 그중 하나를 고르는 일입니다. 이 점들의 배치를 성상도(constellation), 고른 점 하나를 심볼이라고 부릅니다. 점이 M개면 심볼 하나가 log2M비트를 나릅니다.

비트 배정에는 그레이 코드(Gray code)를 씁니다. 이웃한 점끼리는 한 비트만 다르게 배정해 두면, 잡음 때문에 옆 점으로 잘못 판정해도 비트 오류는 하나뿐입니다. 비트율과 심볼률의 관계는 Rb = Rs · log2M입니다. 1 Msym/s의 QPSK는 2 Mbps입니다.

펄스 성형: 점과 점 사이를 어떻게 잇나

심볼을 한 샘플씩 찍고 그 사이를 그냥 유지하면(직사각형 펄스) 파형에 급격한 계단이 생기고, 스펙트럼은 sinc 모양으로 멀리까지 퍼져 옆 채널을 침범합니다. 그래서 심볼마다 부드러운 펄스 모양을 입혀 대역폭을 제한하는데, 이것을 펄스 성형(pulse shaping)이라고 합니다. 구현은 7장의 인터폴레이션 그대로입니다. 심볼 사이에 0을 끼우고(심볼당 샘플 수 sps만큼) 성형 필터를 통과시킵니다.

펄스를 아무렇게나 고를 수는 없습니다. 이웃 심볼의 펄스 꼬리가 현재 심볼의 판정 시점에 겹치면 심볼 간 간섭(ISI)이 생깁니다. 나이퀴스트가 찾은 조건은 "펄스가 다른 모든 심볼의 판정 시점에서 정확히 0일 것"이고, 이를 만족하면서 대역폭을 조절할 수 있는 것이 상승 코사인(raised cosine) 펄스입니다. 롤오프 계수 β(0~1)가 대역폭과 꼬리 길이를 맞바꿉니다.

점유 대역폭 = Rs (1 + β) RF에서의 폭. β = 0.35인 1 Msym/s 신호는 1.35 MHz를 쓴다. β가 작을수록 좁지만 꼬리가 길어 타이밍 오차에 민감하다

실제로는 상승 코사인을 반으로 나눈 루트 상승 코사인(RRC) 필터를 송신기와 수신기에 하나씩 둡니다. 두 RRC를 이으면 상승 코사인이 되어 ISI가 없고, 동시에 수신 RRC는 송신 펄스와 같은 모양이라 정합 필터(matched filter)가 됩니다. 정합 필터는 백색 잡음 속에서 판정 시점의 SNR을 최대로 만드는 필터로, 직관적으로는 "기다리는 모양과 가장 닮은 것을 찾는 상관기"입니다. 송신 성형과 수신 잡음 제거를 한 쌍의 필터로 동시에 해결하는 셈입니다.

import numpy as np from math import erfc, sqrt from mini_rx import rrc, qpsk_map, qpsk_demap # book code: signal-processing-for-rf/code/ SPS = 4 h = rrc(beta=0.35, sps=SPS, span=8) rng = np.random.default_rng(10) def run(ebn0_db, nsym=100_000): bits = rng.integers(0, 2, 2 * nsym) up = np.zeros(nsym * SPS, complex); up[::SPS] = qpsk_map(bits) tx = np.convolve(up, h) # TX pulse shaping n0 = 10 ** (-(ebn0_db + 10 * np.log10(2)) / 10) # Es/N0 = Eb/N0 + 3 dB for QPSK rx = tx + np.sqrt(n0 / 2) * (rng.standard_normal(len(tx)) + 1j * rng.standard_normal(len(tx))) y = np.convolve(rx, h) # RX matched filter d = len(h) - 1 # total delay of RRC + RRC sym = y[d: d + nsym * SPS: SPS] # sample at the eye opening return np.mean(qpsk_demap(sym) != bits) print(f"{'Eb/N0':>6} {'simulated':>10} {'theory':>10}") for e in (2, 4, 6, 8): print(f"{e:4d} dB {run(e):10.2e} {0.5 * erfc(sqrt(10 ** (e / 10))):10.2e}")

시뮬레이션이 이론 곡선 Pb = ½ erfc(√(Eb/N0))와 겹칩니다. RRC 두 개로 ISI 없이 정합 필터링이 되었다는 증거입니다. 펄스 성형을 잘못하면(예: 수신 RRC 생략, 판정 시점 어긋남) 이 곡선에서 바로 벗어납니다.

품질을 재는 숫자들

  • Es/N0와 Eb/N0: 심볼(비트) 하나의 에너지 대 잡음 전력 밀도. Eb/N0 = Es/N0 − 10 log10(log2M). QPSK는 3 dB 차이입니다. 변조 방식끼리 공정하게 비교할 때는 Eb/N0를 씁니다.
  • EVM(Error Vector Magnitude): 받은 점과 이상적인 점 사이 오차 벡터의 RMS를 기준 점의 RMS로 나눈 값. %나 dB(20 log10)로 씁니다. 잡음이 주원인이면 EVM2 ≈ 1 / SNR이므로 EVM −20 dB(10%) ≈ SNR 20 dB입니다. 송신기·수신기 품질을 한 숫자로 말할 때 씁니다.
  • BER/SER: 비트(심볼) 오류율. 최종 성능이지만 재는 데 많은 비트가 필요합니다. 10−6을 확인하려면 수백만 비트를 보내야 합니다.

임베디드 엔지니어의 눈으로

성상도는 RF 신호용 로직 분석기입니다. 디지털 버스를 디버깅할 때 오실로스코프로 눈(eye) 패턴부터 보듯, 수신기를 디버깅할 때는 성상도와 EVM부터 봅니다. 그리고 숫자로 남기세요. "그림이 좀 지저분하다"가 아니라 "EVM −18 dB, 회전 속도 0.002 사이클/심볼"이라고 기록해야 수정 전후를 비교할 수 있습니다.

흔한 함정
  • SNR 정의 혼동: 샘플당 SNR, Es/N0, Eb/N0는 서로 다릅니다. sps = 4로 오버샘플링하면 샘플당 SNR은 Es/N0보다 약 6 dB 낮습니다. 시뮬레이션 잡음을 넣을 때 무엇을 기준으로 했는지 반드시 적으세요.
  • 필터 지연 계산: RRC 두 개의 지연은 필터 길이 − 1 샘플입니다. 이걸 틀리면 판정 시점이 어긋나 ISI가 생기고, BER 곡선이 이론에서 멀어집니다.
  • 그레이 코드 생략: 자연 이진 순서로 배정하면 이웃 점 오판정이 2비트 오류가 되어 BER이 나빠집니다.
핵심 정리
  • 심볼 = 성상도의 점. Rb = Rs log2M. 그레이 코드로 배정한다.
  • RRC 송신 + RRC 수신 = ISI 없는 상승 코사인 + 정합 필터. 대역폭 Rs(1+β).
  • EVM² ≈ 1/SNR. 성상도의 모양이 결함의 종류를 알려 준다.

벤치에서 본 회전, 링, 덩어리는 실제 수신기에서는 항상 동시에 일어납니다. 송신기와 수신기는 서로 다른 수정 발진기로 움직이기 때문입니다. 다음 장에서는 이 차이를 수신기 스스로 측정하고 따라가게 만드는 동기화를 다룹니다.
