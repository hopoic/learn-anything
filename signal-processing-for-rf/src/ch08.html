Part III · RF 수신 체인 실무 — 8장

믹싱, NCO, DDC

이 장을 마치면: 복소 곱셈으로 스펙트럼을 원하는 만큼 옮기고, 위상 누산기 NCO를 설계해 주파수 해상도와 스퓨리어스를 계산하며, NCO·믹서·데시메이터를 묶은 DDC를 구현하고, 직접 변환 수신기의 DC 오프셋과 IQ 불균형을 진단할 수 있습니다.

곱하면 주파수가 움직인다

3장에서 복소수 곱셈은 각도의 덧셈이라고 했습니다. 주파수 f1로 도는 신호에 e−j2πf0n/fs를 곱하면 각도가 매 샘플 그만큼씩 덜 늘어나므로 결과는 f1 − f0로 돕니다. 신호 하나가 아니라 스펙트럼 전체에 똑같이 적용되므로 스펙트럼이 통째로 −f0만큼 평행 이동합니다. 다른 성분은 생기지 않습니다.

y[n] = x[n] · e−j2πf0n/fs  ⇔  Y(f) = X(f + f0)

실수 코사인을 곱하면 이야기가 다릅니다. cos는 반대로 도는 두 화살표의 합이므로 스펙트럼이 +f0와 −f0 두 방향으로 동시에 옮겨집니다. 합 주파수와 차 주파수가 함께 나오고, 원치 않는 쪽(이미지)을 필터로 제거해야 합니다. 아날로그 믹서가 겪는 이미지 문제의 근원이고, 디지털 영역에서 복소 믹싱을 쓰면 이 문제가 처음부터 없습니다. 비용은 복소 곱셈 하나, 즉 실수 곱셈 4번(입력이 실수면 2번)입니다.

NCO: 위상 누산기 하나와 사인 표 하나

믹싱에 쓸 e−j2πf0n/fs는 FPGA 안에서 수치 제어 발진기(NCO, Numerically Controlled Oscillator)가 만듭니다. 구조는 놀랄 만큼 단순합니다. N비트 누산기가 매 클록 주파수 튜닝 워드(FTW)를 더하고, 누산기 값의 윗부분을 주소로 사인·코사인 표를 읽습니다. 누산기가 넘쳐 0으로 돌아가는 것이 정확히 한 바퀴(2π)입니다. 2의 보수 오버플로가 위상의 랩어라운드와 일치한다는 점이 이 설계의 아름다움입니다.

FTW = round( f0 · 2Nfs ),   해상도 Δf = fs2N 예: N = 32, fs = 61.44 MHz → 약 0.0143 Hz 간격으로 튜닝. 음의 FTW(2의 보수)는 음의 주파수

누산기는 32비트라도 표를 232칸으로 만들 수는 없으니 상위 P비트(예: 10비트, 1024칸)만 주소로 씁니다. 버린 하위 비트 때문에 위상이 계단처럼 오차를 갖고, 이 오차가 주기적이라서 스펙트럼에 스퓨리어스로 나타납니다. 널리 쓰는 어림값은 위상 비트 1개당 약 6 dB, 즉 최악의 스퓨리어스가 대략 −6.02P dBc입니다. 10비트 주소면 약 −60 dBc입니다. 사인파의 대칭을 이용해 4분의 1 주기만 저장하면 같은 메모리로 2비트를 더 얻습니다. 메모리 대신 곱셈 없이 시프트와 덧셈만으로 회전을 계산하는 CORDIC 알고리즘을 쓰기도 합니다.

DDC: 옮기고, 거르고, 줄인다

디지털 다운컨버터(DDC)는 지금까지 배운 것을 한 줄로 이은 것입니다. 광대역으로 캡처한 IQ 신호에 NCO를 곱해 원하는 채널을 0 Hz로 옮기고(8장), 저역통과로 그 채널만 남기고(6장), 샘플률을 채널 폭에 맞게 줄입니다(7장). 수신 체인에서 하드웨어 LO가 대략적인 튜닝을, DDC가 정밀한 채널 선택을 맡습니다. RFSoC의 RF-ADC 타일에도 NCO와 복소 믹서, 데시메이션 필터로 된 DDC가 하드 블록으로 들어 있습니다.

데시메이션 전 저역통과 필터

광대역 캡처에 세 개의 "방송국" A(−600 kHz), B(+250 kHz, 가장 약함), C(+700 kHz)가 있습니다. NCO를 250 kHz에 두면 B가 0 Hz로 옮겨지고, 필터와 ↓8을 거치면 250 kHz 폭의 출력에 B만 남습니다. 이제 필터를 끄세요. 버려진 대역에 있던 A와 C가 접혀 들어와 B를 덮습니다. 7장의 "거르고 나서 버린다"를 눈으로 확인하는 순간입니다. NCO를 −600 kHz로 옮기면 A가 선택됩니다.

import numpy as np from scipy import signal fs, N = 2e6, 1 << 15 n = np.arange(N) rng = np.random.default_rng(5) # Wideband capture: three narrowband "stations" plus noise x = (1.00 * np.exp(2j * np.pi * -600e3 / fs * n) + 0.10 * np.exp(2j * np.pi * (250e3 + 3e3) / fs * n) # station B sits 3 kHz above 250 kHz + 0.30 * np.exp(2j * np.pi * 700e3 / fs * n) + 1e-3 * (rng.standard_normal(N) + 1j * rng.standard_normal(N))) def ddc(x, f0, fs, M, ntaps=129): nco = np.exp(-2j * np.pi * f0 / fs * np.arange(len(x))) # NCO y = x * nco # complex mixer: shift by -f0 h = signal.firwin(ntaps, 0.8 / M) # anti-alias, cutoff 0.4 * fs/M return signal.lfilter(h, 1, y)[::M], fs / M # filter, then decimate y, fs_out = ddc(x, 250e3, fs, M=8) Y = np.fft.fftshift(np.abs(np.fft.fft(y[200:] * np.hanning(len(y) - 200)))) f = np.fft.fftshift(np.fft.fftfreq(len(y) - 200, 1 / fs_out)) print(f"output rate {fs_out / 1e3:.0f} kSPS, strongest component at {f[np.argmax(Y)] / 1e3:+.2f} kHz") Ydb = 20 * np.log10(Y / Y.max()) print(f"worst other component: {np.max(Ydb[np.abs(f) > 10e3]):.1f} dB relative to station B")

직접 변환 수신기의 흠과 오프셋 튜닝

AD9361 같은 직접 변환(zero-IF) 수신기는 RF를 한 번에 0 Hz로 내리므로 구조가 단순하고 집적하기 좋지만, 아날로그 IQ 믹서의 불완전함이 0 Hz 주변에 그대로 드러납니다.

  • DC 오프셋과 LO 누설: LO 신호가 자기 자신과 섞이거나 회로의 오프셋이 더해져 정확히 0 Hz에 스파이크가 생깁니다. 트랜시버의 DC 보정이 대부분 지우지만 완벽하지는 않습니다.
  • IQ 불균형: I 경로 이득이 Q 경로보다 ε만큼 크거나, 두 LO의 위상차가 90°에서 φ만큼 어긋나면 +f의 신호가 −f에 거울상을 만듭니다. 오차가 작을 때 이미지 제거비(IRR)는 대략 다음과 같습니다.
IRR ≈ 10 log10 4ε² + φ²  [dB] ε는 이득 오차 비율, φ는 위상 오차(라디안). 이득 1%, 위상 1°면 약 40 dB

해결책은 대개 디지털에서 찾습니다. 첫째, 하드웨어 LO를 관심 신호에서 일부러 조금 비켜(오프셋 튜닝) 신호가 0 Hz가 아닌 곳에 오게 하고, 마지막 정밀 튜닝은 DDC의 NCO로 합니다. 그러면 DC 스파이크는 DDC의 저역통과 필터 밖으로 밀려나 사라집니다. 둘째, 이미지는 대역 안의 다른 신호 위치에 따라 문제가 되기도 하고 안 되기도 하니, 강한 신호의 거울 위치에 약한 관심 신호가 오지 않도록 LO를 고릅니다. 셋째, 남은 불균형은 트랜시버의 직교 보정이나 디지털 IQ 보정 블록으로 줄입니다.

import numpy as np def image_rejection_db(eps, phi_deg, N=4096): """Measure the image of a +f tone after a receiver with IQ gain/phase error.""" n = np.arange(N); phi = np.deg2rad(phi_deg) th = 2 * np.pi * 300 / N * n # tone exactly on bin +300 i = (1 + eps / 2) * np.cos(th) # I path a bit hot q = (1 - eps / 2) * np.sin(th + phi) # Q path a bit cold and skewed X = np.abs(np.fft.fft(i + 1j * q)) return 20 * np.log10(X[300] / X[-300]) # wanted (+f) over image (-f) for eps, ph in ((0.01, 1.0), (0.05, 3.0)): approx = 10 * np.log10(4 / (eps ** 2 + np.deg2rad(ph) ** 2)) print(f"gain {eps:.0%}, phase {ph} deg: measured {image_rejection_db(eps, ph):.1f} dB, approx {approx:.1f} dB")
FPGA 엔지니어의 눈으로

DDC는 PL에서 가장 먼저 만들어 볼 만한 블록입니다. 입력은 트랜시버 인터페이스 코어가 내놓는 IQ 스트림, 출력은 DMA로 가는 낮은 샘플률 IQ 스트림, 제어는 PS가 AXI-Lite 레지스터로 쓰는 FTW와 데시메이션 비율 하나씩입니다. NCO는 블록 RAM 하나, 복소 믹서는 DSP 슬라이스 3~4개, 데시메이터는 CIC나 하프밴드 몇 단으로 Z-7020에 넉넉히 들어갑니다. 레지스터 맵, 스트림 핸드셰이크(tvalid/tready), 리셋 순서처럼 익숙한 문제들이 신호처리 블록에서도 그대로 중요합니다.

흔한 함정
  • 부호 반대: 다운컨버전에는 e−j…가 필요합니다. e+j…를 곱하면 신호가 0 Hz가 아니라 2f0 쪽으로 갑니다. 테스트 톤으로 방향부터 확인하세요.
  • NCO 출력 크기: 표를 32767로 채우면 곱셈 결과가 정확히 215배가 되지 않습니다(32767 ≠ 32768). 이득 오차가 문제가 되는 곳에서는 스케일을 명시적으로 보정하세요.
  • 필터를 넉넉히: 데시메이션 필터의 저지대역이 약하면 인접 채널의 강한 신호가 접혀 들어옵니다. 사양은 가장 강한 인접 신호를 기준으로 정합니다.
핵심 정리
  • 복소 지수를 곱하면 스펙트럼이 평행 이동한다. 실수 코사인은 양쪽으로 옮겨 이미지를 만든다.
  • NCO = 위상 누산기 + 사인 표. 해상도 fs/2N, 위상 비트 1개당 스퓨리어스 약 6 dB.
  • DDC = NCO × 입력 → 저역통과 → ↓M. LO는 비켜 두고 DDC로 정밀 튜닝하면 DC 문제를 피한다.

지금까지는 모든 계산을 실수로 했습니다. 하지만 FPGA에는 부동소수점이 기본으로 없고, 비트 하나하나가 자원입니다. 다음 장에서는 이 모든 블록을 정수로 옮기는 방법, 그리고 PL과 PS 사이에 일을 나누는 방법을 다룹니다.
