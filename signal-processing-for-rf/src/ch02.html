Part I · 신호의 언어 — 2장

샘플링과 앨리어싱

이 장을 마치면: 임의의 주파수가 주어진 샘플률에서 어떤 주파수로 보일지 계산할 수 있고, 나이퀴스트 조건과 안티앨리어싱 필터가 왜 필요한지 설명하며, 나이퀴스트 존을 이용한 대역통과 샘플링을 이해할 수 있습니다.

사인파 하나를 완전히 기술하는 세 숫자

모든 이야기는 사인파에서 시작합니다. 진폭 A, 주파수 f, 위상 φ, 이 세 숫자면 사인파 하나가 완전히 정해집니다.

x(t) = A cos(2πf t + φ) 각주파수 ω = 2πf [rad/s], 주기 T = 1/f

주파수 f는 1초에 몇 바퀴 도는가, 2πf t는 지금까지 몇 라디안 돌았는가입니다. 3장에서 이 "돈다"는 표현이 비유가 아니라 문자 그대로라는 것을 보게 됩니다.

샘플링은 시간축을 일정 간격으로 자른다

ADC는 Ts = 1/fs 간격으로 신호 값을 읽습니다. n번째 샘플은 t = nTs에서의 값이므로 식에 그대로 넣으면 됩니다.

x[n] = x(nTs) = A cos(2π ffs n + φ)

여기서 놀라운 사실이 드러납니다. 샘플열에는 f와 fs가 따로 남지 않고 비율 f/fs만 남습니다. 이 비율을 정규화 주파수(normalized frequency)라고 하고 단위는 "샘플당 사이클"입니다. 숫자열만 보고는 1 MSPS로 받은 100 kHz인지, 10 MSPS로 받은 1 MHz인지 알 수 없습니다. 둘 다 0.1 사이클/샘플입니다.

더 중요한 성질이 있습니다. 주파수에 fs의 정수배를 더해 보세요.

cos(2π f + k fsfs n + φ) = cos(2π ffs n + 2πkn + φ) = cos(2π ffs n + φ) k와 n이 정수이므로 2πkn은 정확히 몇 바퀴. 각도가 제자리로 돌아온다.

샘플만 보면 f와 f + fs와 f + 2fs는 완전히 같은 숫자열입니다. 이것이 앨리어싱(aliasing)입니다. 이산 시간 세계에서 주파수는 직선이 아니라 둘레가 fs인 원 위에 있습니다. 게다가 실수 코사인은 cos(−θ) = cos θ이므로 −f와 f도 구분되지 않습니다. 둘을 합치면 실수 신호에서 보이는 주파수는 항상 0부터 fs/2 사이로 "접혀" 들어옵니다.

falias = | f − k fs |,   k = round(f / fs) 결과는 항상 0 ≤ falias ≤ fs/2

슬라이더를 500 Hz 너머로 밀어 보세요. 연속 파형은 점점 빨리 흔들리는데 샘플 점들이 그리는 주황색 곡선은 오히려 느려집니다. 1000 Hz에서는 샘플이 매번 같은 위상을 찍어 직류(0 Hz)처럼 보이고, 1300 Hz는 300 Hz와 점 하나하나까지 똑같습니다. 아래 그래프의 지그재그가 "주파수가 접힌다"는 말의 모양입니다.

나이퀴스트 조건: 대역폭의 두 배보다 빠르게

접힘이 문제가 되지 않으려면 신호의 모든 성분이 처음부터 0 ~ fs/2 안에 있어야 합니다. 최고 주파수가 B인 실수 신호라면 fs > 2B. 이것이 나이퀴스트-섀넌 샘플링 정리의 실무적 요약이고, fs/2를 나이퀴스트 주파수라고 부릅니다. 이 조건을 만족하면 샘플로부터 원래 연속 신호를 정확히 복원할 수 있습니다.

부등호가 엄격하다는 점에 주의하세요. f = fs/2를 정확히 샘플링하면 cos(πn + φ) = cos φ · (−1)n이 됩니다. 크기가 위상에 따라 달라지고, φ = 90°면 모든 샘플이 0입니다. 신호가 통째로 사라집니다.

3장에서 다룰 복소(IQ) 샘플링에서는 같은 조건이 fs > B로 바뀝니다. PlutoSDR이 "샘플률 20 MSPS로 20 MHz 대역폭"을 볼 수 있는 이유입니다.

import numpy as np fs = 1000.0 n = np.arange(12) def samples(f, phase=0.0): return np.cos(2 * np.pi * f / fs * n + phase) # 300 Hz and its aliases produce identical sample sequences for f in (1300, 700, 1700): print(f"{f:5.0f} Hz equals 300 Hz at fs=1 kHz: {np.allclose(samples(f), samples(300))}") def alias(f, fs): return abs(f - round(f / fs) * fs) print("alias of 2310 Hz:", alias(2310, fs), "Hz") # Sampling exactly at 2*f: the result depends on phase and can vanish print("f = fs/2, phase 90 deg:", np.round(samples(500, np.pi / 2)[:6], 12))

안티앨리어싱 필터와 오버샘플링

앨리어싱은 샘플링 이후에는 되돌릴 수 없습니다. 1300 Hz 간섭이 300 Hz로 접혀 들어오면, 진짜 300 Hz 신호와 구분할 정보가 샘플 안에 아예 없습니다. 그래서 ADC 앞에는 반드시 아날로그 저역통과 필터, 즉 안티앨리어싱 필터를 둡니다. 원하는 신호만이 아니라 잡음도 접힌다는 점이 특히 중요합니다. 나이퀴스트 주파수 위의 광대역 잡음을 걸러 내지 않으면 그 잡음이 전부 대역 안으로 포개져 들어와 잡음 바닥을 올립니다.

현실의 필터는 통과대역에서 저지대역으로 순간적으로 바뀌지 못하고 전이대역(transition band)이 필요합니다. 그래서 실무에서는 fs를 2B보다 넉넉하게 잡습니다. 오디오 CD가 20 kHz 대역에 44.1 kHz를 쓰는 것은 2.05 kHz 폭의 전이대역을 확보하기 위해서입니다.

현대 RF 트랜시버는 이 문제를 반대 방향으로 풉니다. AD9361 계열의 ADC는 연속 시간 시그마-델타 방식으로 수백 MSPS(FMCOMMS2 문서 기준 640 MSPS)라는 아주 높은 속도로 샘플링하고, 그 뒤에 디지털 데시메이션 필터로 날카로운 필터링을 하면서 샘플률을 내립니다. 아날로그 필터는 느슨해도 되고, 어려운 일은 정확하고 재현 가능한 디지털 필터가 맡습니다. 이 구조는 7장에서 자세히 뜯어봅니다.

일부러 접기: 나이퀴스트 존과 대역통과 샘플링

앨리어싱이 항상 적은 아닙니다. 주파수 축을 fs/2 폭의 구간으로 나누면 각 구간이 나이퀴스트 존(zone)입니다. 1존은 0 ~ fs/2, 2존은 fs/2 ~ fs, 3존은 fs ~ 1.5fs입니다. 신호가 한 존 안에만 들어 있다면, 그 존 전체가 1존으로 고스란히 접혀 들어오므로 정보가 겹치지 않습니다. 짝수 존은 거울에 비친 것처럼 주파수가 뒤집혀(spectral inversion) 들어온다는 점만 기억하면 됩니다.

이것이 대역통과 샘플링(언더샘플링)입니다. 예를 들어 fs = 1000 Hz에서 1200–1400 Hz 대역은 3존이고, 200–400 Hz로 뒤집힘 없이 나타납니다. 최고 주파수의 두 배보다 훨씬 낮은 샘플률로 받은 셈입니다. 대신 앞단에 그 존만 남기는 아날로그 대역통과 필터가 꼭 있어야 합니다. 다른 존의 신호도 똑같이 접혀 들어오기 때문입니다. Zynq UltraScale+ RFSoC의 RF-ADC처럼 기가샘플급 ADC가 믹서 없이 RF를 직접 샘플링할 때 이 원리를 씁니다.

흔한 함정
  • "2배면 충분하다": 정확히 2배에서는 위상에 따라 신호가 사라질 수 있고, 현실의 필터에는 전이대역이 필요합니다. 여유를 두세요.
  • 샘플률만 바꾸고 필터는 그대로: PlutoSDR에서도 sample_rate와 아날로그 필터 대역폭 rx_rf_bandwidth는 별개의 설정입니다. 샘플률을 낮추고 필터를 넓게 두면 대역 밖 신호가 접혀 들어옵니다.
  • 디지털 처리 중의 앨리어싱: 샘플을 솎아 내는 데시메이션도 샘플링입니다. 미리 거르지 않고 버리면 ADC 앞에서 막았던 앨리어싱이 디지털 영역에서 다시 일어납니다(7장).
핵심 정리
  • 샘플열에는 f/fs만 남는다. f와 f + k fs는 구분할 수 없다.
  • 실수 신호는 fs > 2B, 복소 신호는 fs > B.
  • 앨리어싱은 샘플링 뒤에는 되돌릴 수 없다. 반드시 샘플링 전에 거른다.

그런데 실수 신호에서 왜 f와 −f가 구분되지 않는지, "음의 주파수"란 도대체 무엇인지는 아직 설명하지 않았습니다. 다음 장에서 사인파를 회전하는 화살표로 바꿔 보면 이 질문과 함께 RF 수신기가 왜 I와 Q 두 채널을 쓰는지가 한꺼번에 풀립니다.
