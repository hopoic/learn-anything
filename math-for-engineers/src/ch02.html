Part I · 수학의 언어 — 2장

함수와 그래프

이 장을 마치면: 함수를 입력과 출력을 가진 상자로 보고 그래프에서 값을 읽을 수 있고, 직선 y = ax + b의 기울기와 절편을 단위와 함께 해석해 센서 2점 보정과 선형 보간을 할 수 있으며, 2차·지수·주기 함수의 모양을 구분하고 그래프를 옮기고 늘리는 규칙을 쓸 수 있습니다.

함수는 입력을 받아 출력을 돌려주는 상자다

1장에서 수식이 코드라고 했습니다. 그 코드의 기본 단위가 함수입니다. 수학의 함수는 C 함수와 거의 같습니다. 값을 하나 넣으면 값이 하나 나옵니다. 다만 수학의 함수는 전역 변수를 건드리지 않는 순수 함수입니다. 같은 입력을 넣으면 언제나 같은 출력이 나옵니다.

그래프는 이 상자에 가능한 입력을 전부 넣어 보고, (입력, 출력) 쌍을 점으로 찍어 이은 그림입니다. 가로축(x축)이 입력, 세로축(y축)이 출력입니다. 그래프를 읽는다는 것은 "가로로 여기쯤이면 세로로 얼마인가"를 읽는 것이고, 더 중요하게는 "입력이 늘 때 출력이 어떻게 변하는가"라는 모양을 읽는 것입니다.

임베디드 엔지니어의 눈으로

써미스터 온도표처럼 함수를 계산하는 대신 표로 저장해 두는 것이 룩업 테이블(LUT)입니다. 표는 함수의 그래프에서 점 몇 개를 뽑아 둔 것이고, 점 사이 값은 아래에서 배울 선형 보간으로 채웁니다.

직선: 기울기는 "입력이 1 늘 때 출력이 얼마나"

가장 중요한 함수는 직선입니다. 공학에서 "선형(linear)"이라는 말이 나오면 대개 이 모양이 숨어 있습니다.

y = a · x + b a: 기울기(slope) · b: 절편(intercept), 즉 x = 0일 때의 y

읽는 법: "x가 1 늘 때마다 y는 a씩 늘고, 출발점은 b다."

기울기는 두 점 사이에서 세로 변화량 ÷ 가로 변화량, 즉 Δy/Δx입니다. 기울기에는 반드시 단위가 있다는 점이 중요합니다. 0°C에서 500 mV를 내고 1°C 오를 때마다 10 mV씩 오르는 온도 센서라면 V = 10 [mV/°C] · T + 500 [mV]입니다. 기울기의 단위 mV/°C를 보면 무엇을 무엇으로 나눈 값인지 바로 알 수 있습니다.

이 식을 거꾸로 풀면 전압에서 온도를 구할 수 있습니다. 양변에서 500을 빼고 10으로 나누면 T = (V − 500) / 10. 펌웨어가 하는 "변환"이 바로 이 역함수 계산입니다.

두 점이면 직선이 정해진다: 2점 보정과 선형 보간

실제 센서는 데이터시트 값과 조금씩 다릅니다. 그래서 알려진 두 조건에서 원시값(raw)을 읽어 직선을 직접 만듭니다. 예를 들어 12비트 ADC가 25.0°C에서 1240, 75.0°C에서 1860을 읽었다면 두 점 (1240, 25.0)과 (1860, 75.0)이 생깁니다.

a = y2 − y1x2 − x1 = 75.0 − 25.01860 − 1240 ≈ 0.0806 °C/count,   b = y1 − a x1 = −75.0 °C

이제 raw = 1500이면 T = 0.0806 × 1500 − 75.0 ≈ 46.0°C입니다. 같은 계산을 표의 이웃한 두 점 사이에서 하면 선형 보간(lerp, linear interpolation)이 됩니다. "두 점 사이를 직선으로 이었다고 치고 그 위의 값을 읽는다"는 뜻입니다.

y = y1 + (y2 − y1) · x − x1x2 − x1 오른쪽 분수는 "x가 두 점 사이 몇 % 지점에 있는가" (0이면 왼쪽 점, 1이면 오른쪽 점)
import numpy as np # Two known points: (raw ADC count, temperature in degC) x1, y1 = 1240, 25.0 x2, y2 = 1860, 75.0 a = (y2 - y1) / (x2 - x1) # slope [degC per count] b = y1 - a * x1 # intercept [degC] print(f"T = {a:.5f} * raw {b:+.2f}") print(f"raw 1500 -> {a * 1500 + b:.2f} degC") def lerp(x, xa, ya, xb, yb): t = (x - xa) / (xb - xa) # 0 at the left point, 1 at the right point return ya + (yb - ya) * t # A thermistor lookup table: interpolate between neighbouring entries raw_tab = [800, 1200, 1600, 2000, 2400] deg_tab = [-10.0, 12.0, 31.0, 47.0, 61.0] raw = 1750 i = np.searchsorted(raw_tab, raw) - 1 print("table lerp :", lerp(raw, raw_tab[i], deg_tab[i], raw_tab[i + 1], deg_tab[i + 1])) print("np.interp :", np.interp(raw, raw_tab, deg_tab))

직선이 아닌 함수들의 얼굴

세상이 전부 직선이면 좋겠지만 그렇지 않습니다. 공학에서 자주 만나는 함수는 몇 가지 얼굴로 나뉘고, 모양을 보면 어떤 현상인지 짐작할 수 있습니다.

종류식의 꼴모양어디서 만나나
직선(1차)ax + b일정하게 오르거나 내림센서 보정, 옴의 법칙 V = IR
2차(포물선)ax2 + bU자, 커질수록 가파름전력 P = I2R, 운동에너지, 제동 거리
지수b · 2ax처음엔 느리다가 폭발(또는 빠르게 사라짐)충전·방전, 냉각, 증폭(3장, 7장)
주기(사인)b · sin(ax)일정한 간격으로 반복교류, 진동, 회전(4장)
실습 벤치 2-A · 함수 놀이터FUNCTIONS
함수 종류

직선에서 a를 음수로 바꾸면 내리막이 되고, a = 0이면 수평선이 됩니다. 2차 함수에서 a가 크면 U자가 좁아지고, 지수 함수에서 a를 음수로 하면 "빠르게 사라지는" 감쇠 곡선이 됩니다. 사인에서 a를 키우면 같은 폭 안에 물결이 더 많이 들어갑니다. 아래쪽 점선이 "입력 x를 넣으면 출력이 얼마인가"를 그래프에서 읽는 법입니다.

그래프를 옮기고 늘리는 네 가지 규칙

어떤 함수 f(x)든 아래 네 가지 조작으로 위치와 크기를 바꿀 수 있습니다. 4장에서 사인파의 위상을 다룰 때 바로 쓰게 됩니다.

바꾼 식그래프에 일어나는 일예
f(x) + c위로 c만큼 이동센서 오프셋
f(x − c)오른쪽으로 c만큼 이동 (빼는데 오른쪽!)신호 지연
k · f(x)세로로 k배 늘림증폭기 이득
f(kx)가로로 1/k배 압축주파수를 k배로

f(x − c)가 오른쪽으로 가는 이유는 이렇게 생각하면 쉽습니다. 원래 x = 0에서 일어나던 일이 이제는 x − c = 0, 즉 x = c가 되어야 일어납니다. 같은 사건이 c만큼 늦게 일어나니 그래프가 오른쪽으로 밀립니다.

흔한 함정
  • 단위 없는 기울기: 기울기 0.0806이라고만 적으면 무엇의 0.0806인지 알 수 없습니다. 항상 "°C/count"처럼 단위를 붙이세요.
  • 보정 범위 밖으로 외삽: 25–75°C에서 만든 직선을 −20°C에 그대로 쓰면, 센서가 그 범위에서 직선이 아닐 경우 오차가 커집니다. 보정 점은 실제 사용 범위의 양끝 근처에 잡습니다.
  • 정수 나눗셈: C에서 (y2 - y1) / (x2 - x1)를 정수로 계산하면 50/620 = 0이 됩니다. 고정소수점이라면 곱셈을 먼저 하고 나중에 나눕니다.
핵심 정리
  • 함수 = 입력을 출력으로 바꾸는 순수한 규칙, 그래프 = 그 규칙의 모양.
  • 직선의 기울기 = Δy/Δx, 단위를 붙여 읽는다. 두 점이면 직선이 정해진다.
  • f(x − c)는 오른쪽 이동, k·f는 세로로 늘림, f(kx)는 가로로 압축.

직선은 "더해서" 늘어나는 함수입니다. 그런데 "곱해서" 늘어나는 현상, 예를 들어 비트 수가 하나 늘면 표현 범위가 두 배가 되는 일은 직선으로 다룰 수 없습니다. 다음 장에서 이런 현상을 다루는 지수와, 그것을 거꾸로 묻는 로그를 익힙니다. 데시벨도 거기서 나옵니다.
