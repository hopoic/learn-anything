미분: 순간의 기울기

이 장을 마치면: 미분을 "아주 짧은 구간에서 잰 기울기"로 설명할 수 있고, 위치·속도·가속도의 관계를 미분으로 읽으며, 기본 미분 규칙 몇 개로 최댓값 문제를 풀고, 센서 데이터를 수치 미분할 때 잡음이 커지는 이유와 대처법을 알게 됩니다.

평균 속도에서 순간 속도로

2장에서 직선의 기울기는 Δy/Δx라고 했습니다. 직선은 어디서 재도 기울기가 같습니다. 그런데 곡선은 위치마다 기울기가 다릅니다. 차가 출발해서 가속할 때, "지금 이 순간의 속도"는 얼마일까요?

위치를 x(t)라고 하면 1초 동안의 평균 속도는 (x(t+1) − x(t)) / 1입니다. 그래프에서는 곡선 위 두 점을 잇는 직선(할선)의 기울기입니다. 이제 간격을 0.1초, 0.01초, 0.001초로 줄여 가면, 두 점이 거의 붙으면서 할선이 곡선에 살짝 닿는 직선(접선)에 다가갑니다. 간격을 한없이 줄였을 때 기울기가 다가가는 값, 그것이 미분입니다.

f ′(x) =  limh→0 f(x + h) − f(x)h 다른 표기: dfdx, dydx. 여기서 d는 "아주아주 작은 Δ"라는 뜻

소리 내어 읽기: "f 프라임 x는, h를 0으로 보낼 때 'f(x+h) 빼기 f(x), 나누기 h'가 다가가는 값이다." lim(극한, limit)은 "그 값에 다가간다"는 뜻입니다. h를 정말 0으로 만들면 0/0이 되니까, 0에 "다가가게만" 하는 것입니다.

컴퓨터에서는 lim을 계산할 수 없으니 h를 충분히 작은 값으로 두고 그냥 나눕니다. 그것이 수치 미분이고, 펌웨어가 늘 하는 (x[k] - x[k-1]) / dt입니다.

매번 극한을 계산할 필요는 없습니다. 자주 나오는 함수의 미분 결과는 정해져 있고, 공학에서 실제로 쓰는 것은 아래 표 정도입니다.

여기에 규칙 두 개만 더하면 됩니다. 첫째, 선형성: 더한 것의 미분은 미분한 것의 합이고, 상수배는 그대로 밖으로 나옵니다. (3x2 + sin x)′ = 6x + cos x. 둘째, 연쇄 법칙: 안쪽에 함수가 들어 있으면 안쪽의 미분을 곱합니다. 공학에서 가장 흔한 예는 사인파입니다.

ddt sin(ωt) = ω · cos(ωt) 안쪽 ωt가 ω배 빨리 변하니까, 바깥도 ω배 빨리 변한다

이 식은 실용적인 사실 하나를 알려 줍니다. 진폭이 같아도 주파수가 높은 신호일수록 미분값(변화 속도)이 주파수에 비례해 커집니다. 그래서 미분은 고주파를 키우는 연산, 즉 잡음을 키우는 연산입니다. 이 장의 마지막 절에서 다시 만납니다.

위치 → 속도 → 가속도, 그리고 최댓값 찾기

미분은 "변화율"이므로 물리량 사이의 사다리를 만듭니다. 위치 x(t)를 미분하면 속도 v = dx/dt, 속도를 미분하면 가속도 a = dv/dt입니다. 두 번 미분한 것을 2계 미분이라 하고 f ″로 씁니다. 2계 미분은 기울기가 변하는 정도, 즉 곡선이 얼마나 휘었는가입니다.

미분의 가장 강력한 쓰임은 최댓값과 최솟값 찾기입니다. 매끄러운 곡선이 꼭대기나 바닥에 닿는 순간에는 접선이 수평이므로 기울기가 0입니다. 그래서 "f ′(x) = 0인 x를 찾아라"가 최적화 문제의 출발점이 됩니다.

전자과에서 배운 최대 전력 전달이 좋은 예입니다. 내부 저항 Rs인 전원에 부하 R을 달면 부하가 받는 전력은 P(R) = V2R / (R + Rs)2입니다. R이 너무 작으면 전압이 안 걸리고, 너무 크면 전류가 안 흐릅니다. 그 사이 어딘가에 꼭대기가 있고, dP/dR = 0을 풀면 R = Rs가 나옵니다. 아래 코드는 이것을 손으로 미분하지 않고 수치로 확인합니다.

import numpy as np V, Rs = 12.0, 4.0 # source voltage [V], internal resistance [ohm] def P(R): return V**2 * R / (R + Rs) ** 2 # power delivered to the load [W] R = np.linspace(0.5, 20, 3901) # sweep the load resistance dP = np.gradient(P(R), R) # numerical derivative dP/dR i = np.where(np.diff(np.sign(dP)) != 0)[0][0] # where the slope changes sign print(f"slope crosses zero at R = {R[i]:.2f} ohm (theory: R = Rs = {Rs} ohm)") print(f"max power = {P(R[i]):.2f} W, at R = 2 ohm: {P(2.0):.2f} W, at R = 8 ohm: {P(8.0):.2f} W")

실전 수치 미분: 잡음이 커지는 이유

엔코더나 위치 센서로 속도를 구할 때 가장 간단한 방법은 연속한 두 샘플의 차를 시간 간격으로 나누는 것입니다.

/* Called every dt seconds from a timer interrupt */ float velocity_update(float pos_now, float dt) { static float pos_prev = 0.0f; float v = (pos_now - pos_prev) / dt; /* backward difference */ pos_prev = pos_now; return v; }

그런데 위치 값에 아주 작은 잡음 ε이 섞여 있다면, 차를 dt로 나누는 순간 잡음은 대략 ε/dt 크기가 됩니다. dt를 줄여 "더 정확한 미분"을 하려 할수록 잡음은 커집니다. 벤치 5-A에서는 h를 줄일수록 좋아졌지만, 그건 잡음 없는 수학 곡선이었기 때문입니다. 아래 실험은 잡음이 0.001밖에 안 되는 위치 신호를 여러 간격으로 미분해 오차를 잽니다.

import numpy as np rng = np.random.default_rng(1) sigma = 0.001 # position noise (tiny!) print(" dt forward-diff error central-diff error") for dt in (0.2, 0.05, 0.01, 0.001): t = np.arange(0, 10, dt) x = np.sin(t) + rng.normal(0, sigma, t.size) # measured position v_true = np.cos(t) v_fwd = (x[1:] - x[:-1]) / dt # (x[k+1] - x[k]) / dt v_cen = (x[2:] - x[:-2]) / (2 * dt) # (x[k+1] - x[k-1]) / 2dt e_fwd = np.sqrt(np.mean((v_fwd - v_true[:-1]) ** 2)) e_cen = np.sqrt(np.mean((v_cen - v_true[1:-1]) ** 2)) print(f"{dt:6.3f} {e_fwd:12.4f} {e_cen:12.4f}")

결과를 보면 간격이 너무 크면 곡선을 직선으로 근사한 오차가 커지고, 너무 작으면 잡음이 폭발합니다. 그 사이에 최적점이 있습니다. 실무에서 쓰는 대처법은 세 가지입니다.

  • 중앙 차분: (xk+1 − xk−1)/2dt. 간격이 같아도 근사 오차가 훨씬 작습니다. 대신 한 샘플 늦게 나옵니다.
  • 미분 전후에 저역통과 필터: 고주파 잡음을 먼저 깎아 냅니다(7장의 1차 필터).
  • 미분하지 말고 추정하기: 위치와 속도를 함께 추정하는 필터를 씁니다(13장의 칼만 필터).
임베디드 엔지니어의 눈으로

PID 제어기의 D항이 바로 오차의 미분입니다. D 이득을 올리면 모터가 "지글거리는" 이유가 이 절에 있습니다. 그래서 대부분의 실전 PID 구현은 D항에 저역통과 필터를 달고, 목표값이 계단처럼 바뀔 때 생기는 미분 폭발(derivative kick)을 피하려 오차 대신 측정값을 미분합니다.

흔한 함정
  • "샘플링을 빠르게 하면 속도가 더 정확해진다": 잡음이 있으면 반대입니다. 엔코더 분해능이 낮으면 짧은 dt에서 차가 0 아니면 1카운트라 속도가 계단처럼 튑니다.
  • 불규칙한 dt: 인터럽트 지터로 실제 간격이 흔들리면, 고정 상수 dt로 나눈 미분값도 흔들립니다. 타임스탬프로 실제 간격을 재서 나누세요.
핵심 정리
  • 미분 = 간격을 한없이 줄였을 때의 기울기 = 순간 변화율. 코드로는 차분 ÷ 간격.
  • xn → nxn−1, sin → cos, ex → ex, 안쪽이 있으면 안쪽의 미분을 곱한다.
  • 꼭대기와 바닥에서는 기울기가 0. 미분은 고주파와 잡음을 키운다.

미분은 "얼마나 빨리 변하나"였습니다. 다음 장에서는 반대 질문, "지금까지 얼마나 쌓였나"를 다룹니다. 속도에서 이동 거리를, 전류에서 배터리 사용량을 구하는 적분입니다. 그리고 미분과 적분이 서로를 되돌리는 연산이라는 것을 보게 됩니다.
