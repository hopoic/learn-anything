Part II · 변화와 누적 — 미적분 — 7장

미분방정식과 시뮬레이션

이 장을 마치면: "변화율이 현재 상태에 달려 있다"는 미분방정식을 읽을 수 있고, 1차 시스템의 시정수 τ와 63%·5τ 규칙을 쓰며, 오일러 방법으로 미분방정식을 루프 코드로 바꾸고 시간 간격이 너무 크면 왜 발산하는지 설명하며, 2차 시스템의 감쇠비가 오버슈트를 정한다는 것을 압니다.

변화율이 상태에 달려 있을 때

저항 R을 거쳐 커패시터 C를 전압 Vin으로 충전한다고 합시다. 처음에는 전압 차가 커서 전류가 많이 흐르고 빠르게 충전됩니다. 커패시터 전압 V가 Vin에 가까워지면 차이가 작아져 전류가 줄고, 충전이 느려집니다. 이 이야기를 식으로 쓰면 이렇습니다.

dVdt = Vin − Vτ,   τ = RC "전압이 변하는 속도는 목표와의 차이에 비례한다"

이렇게 미지의 함수와 그 미분이 함께 들어 있는 식을 미분방정식이라고 합니다. 보통 방정식의 답은 숫자(x = 3)이지만, 미분방정식의 답은 함수(V(t) = …)입니다. "다음 순간이 어떻게 될지를 지금 상태로 정하는 규칙"이라고 생각하면 됩니다. 프로그래머에게 익숙한 말로는 상태 갱신 규칙입니다.

같은 모양의 식이 곳곳에 있습니다. 뜨거운 모터가 주변 온도로 식는 속도(뉴턴의 냉각 법칙), 탱크에서 물이 빠지는 속도, 그리고 디지털 저역통과 필터가 입력을 따라가는 속도가 모두 "목표와의 차이에 비례해 다가간다"입니다.

e와 시정수 τ

위 미분방정식의 답(처음에 V = 0)은 다음과 같습니다.

V(t) = Vin · (1 − e−t/τ) e ≈ 2.71828, 자연로그의 밑

왜 하필 e일까요? 5장 표에서 ex는 미분해도 자기 자신인 유일한 함수라고 했습니다. "변화율이 현재 값에 비례한다"는 규칙을 만족하는 함수가 바로 지수 함수이고, 그 비례 상수가 1이 되게 하는 밑이 e입니다. 그래서 자연의 성장과 감쇠를 쓰면 저절로 e가 나옵니다.

τ(타우)는 시정수(time constant)로, 단위는 초입니다. 10 kΩ과 10 μF이면 τ = 104 × 10−5 = 0.1 s입니다. 아래 표만 기억하면 대부분의 1차 시스템 문제를 암산할 수 있습니다.

목표까지 도달한 비율63.2%86.5%95.0%98.2%99.3%

"1τ면 63%, 5τ면 사실상 끝"이 실무 규칙입니다. 리셋 회로의 지연, 센서 응답 시간, 온도 안정화 대기 시간을 정할 때 씁니다.

오일러 방법: 미분방정식은 루프가 된다

대부분의 미분방정식은 위처럼 깔끔한 답이 없습니다. 그래도 걱정할 필요가 없습니다. 컴퓨터로 한 걸음씩 밟아 가면 됩니다. 아주 짧은 시간 dt 동안은 변화율이 거의 일정하니, "지금 값 + 변화율 × dt"로 다음 값을 구합니다. 이것이 오일러(Euler) 방법입니다.

Vk+1 = Vk + dt · Vin − Vkτ 미분방정식의 dV/dt를 (Vk+1 − Vk)/dt로 바꾸고 정리한 것

이 식을 α = dt/τ로 놓고 코드로 쓰면 놀랍게도 익숙한 모양이 나옵니다.

/* One step of the RC equation = the classic exponential moving average */ float lowpass_step(float y, float x, float alpha) /* alpha = dt / tau */ { return y + alpha * (x - y); /* move a fraction alpha toward the input */ }

센서 값을 부드럽게 할 때 쓰는 y += alpha * (x - y), 즉 지수 이동평균(EMA) 필터는 RC 저역통과 회로의 미분방정식을 오일러 방법으로 푼 것과 정확히 같은 식입니다. α를 고르는 것은 시정수를 고르는 것이고, τ = dt/α입니다. 100 Hz로 갱신하면서 α = 0.1이면 τ = 0.1 s입니다.

간격을 키워 보세요. α가 1보다 작으면 계산값이 모자란 쪽에서 다가가고, 1을 넘으면 목표를 지나쳤다 돌아오기를 반복하며, 2를 넘으면 진동이 점점 커져 발산합니다. 이유는 간단합니다. 목표와의 오차가 한 걸음마다 (1 − α)배가 되는데, α > 2이면 |1 − α| > 1이라 오차가 매번 커집니다. 실제 회로는 절대 발산하지 않으니, 이건 순전히 계산 방법이 만든 가짜 현상입니다. 시뮬레이션이나 제어 루프의 주기를 정할 때 간격은 시스템의 가장 빠른 시정수보다 충분히 짧게(보통 1/10 이하) 잡아야 하는 이유입니다.

import numpy as np tau, Vin, T_end = 1.0, 1.0, 5.0 for ratio in (0.1, 0.5, 1.5, 2.5): dt = ratio * tau n = int(round(T_end / dt)) V, err = 0.0, 0.0 for k in range(n): V = V + dt * (Vin - V) / tau # Euler step exact = Vin * (1 - np.exp(-(k + 1) * dt / tau)) err = max(err, abs(V - exact)) print(f"dt/tau = {ratio:3.1f}: error factor per step {1 - ratio:+.1f}, " f"max error over {n:2d} steps = {err:.3g}") # The 63 % / 5 tau rule for m in (1, 2, 3, 5): print(f"t = {m} tau -> {100 * (1 - np.exp(-m)):.1f} % of the way")

2차 시스템 맛보기: 스프링, 댐퍼, 그리고 오버슈트

로봇 팔이나 서스펜션처럼 질량이 있는 시스템은 상태가 둘입니다. 위치와 속도. 스프링은 위치에 비례해 되돌리는 힘을, 댐퍼는 속도에 비례해 저항하는 힘을 냅니다. 뉴턴의 법칙 F = ma로 쓰면 가속도(2계 미분)가 들어간 2차 미분방정식이 됩니다.

m · x ″ = −k · x − c · x ′ 질량 × 가속도 = 스프링 힘 + 댐퍼 힘

풀 때는 상태를 둘로 나눠 오일러 방법을 그대로 씁니다. 매 걸음 가속도를 구해 속도를 갱신하고, 그 속도로 위치를 갱신합니다. 이 시스템의 성격은 감쇠비 ζ(제타) 하나로 요약됩니다. ζ가 작으면 출렁이며(부족 감쇠), 1이면 출렁임 없이 가장 빨리 도착하고(임계 감쇠), 1보다 크면 굼뜨게 다가갑니다(과감쇠). 제어 루프를 튜닝한다는 것은 결국 닫힌 루프의 ζ와 응답 속도를 고르는 일입니다.

import numpy as np wn = 2 * np.pi * 1.0 # natural frequency: 1 Hz dt = 1e-4 t = np.arange(0, 6, dt) print(" zeta overshoot theory rise(10-90%) settle(2%)") for zeta in (0.1, 0.4, 0.7, 1.0, 2.0): x, v = 0.0, 0.0 # step response toward x = 1 xs = np.empty(t.size) for i in range(t.size): a = wn**2 * (1.0 - x) - 2 * zeta * wn * v # acceleration from the ODE v += a * dt # update velocity first x += v * dt # then position (semi-implicit Euler) xs[i] = x over = max(0.0, xs.max() - 1.0) * 100 theory = 100 * np.exp(-zeta * np.pi / np.sqrt(1 - zeta**2)) if zeta < 1 else 0.0 outside = np.where(np.abs(xs - 1.0) > 0.02)[0] settle = t[outside[-1]] if outside.size else 0.0 settle_s = f"{settle:5.2f} s" if settle < t[-1] - 0.01 else " > 6 s" rise = t[np.argmax(xs >= 0.9)] - t[np.argmax(xs >= 0.1)] print(f" {zeta:3.1f} {over:6.1f} % {theory:6.1f} % {rise:5.2f} s {settle_s}")

표를 보면 ζ가 작을수록 빨리 올라가지만 크게 출렁이고 오래 흔들립니다(ζ = 0.1은 6초가 지나도 자리를 못 잡습니다). ζ가 1을 넘으면 출렁임은 없지만 굼떠집니다. ζ = 0.7 근처는 5% 미만의 오버슈트로 임계 감쇠보다 빨리 올라가면서 정착 시간은 비슷합니다. 실무에서 단골 튜닝 목표가 되는 이유입니다.

임베디드 엔지니어의 눈으로

제어 펌웨어의 메인 루프는 사실상 미분방정식 풀이기입니다. 매 주기 센서로 상태를 읽고, 규칙에 따라 다음 출력을 정하고, 시간이 dt만큼 흐릅니다. ROS 2의 시뮬레이터나 Gazebo 같은 물리 엔진도 같은 일을 훨씬 정교한 적분 방법(룽게-쿠타 등)으로 할 뿐입니다.

흔한 함정
  • 너무 긴 루프 주기: dt가 시스템 시정수에 비해 길면 시뮬레이션도, 이산 제어기도 진동하거나 발산합니다. 실제 하드웨어 문제가 아닌데 코드가 불안정해 보인다면 먼저 dt를 의심하세요.
  • EMA 계수를 주기와 따로 바꾸기: 루프 주기를 바꾸면서 α를 그대로 두면 시정수가 바뀝니다. α = dt/τ로 계산해 두세요.
핵심 정리
  • 미분방정식 = 지금 상태로 변화율을 정하는 규칙 = 상태 갱신 규칙.
  • 1차 시스템: 1τ에 63%, 5τ에 99%. EMA 필터 y += α(x − y)는 RC 회로와 같은 식, τ = dt/α.
  • 오일러 방법: 다음 값 = 지금 값 + 변화율 × dt. dt가 너무 크면 가짜 진동과 발산이 생긴다.
