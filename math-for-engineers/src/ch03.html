지수와 로그

이 장을 마치면: 거듭제곱과 지수 법칙을 써서 비트 수·메모리 크기·과학적 표기를 다룰 수 있고, 로그를 "몇 번 곱했나"로 읽어 필요한 비트 수와 반감기를 계산하며, 데시벨(dB)을 자유롭게 변환하고 로그 눈금 그래프를 해석할 수 있습니다.

지수는 "몇 번 곱했나"다

2장의 직선은 x가 1 늘 때마다 같은 양을 더합니다. 지수는 x가 1 늘 때마다 같은 배수를 곱합니다.

2n = 2 × 2 × … × 2 (n번) 2를 밑(base), n을 지수(exponent)라고 부른다

임베디드 엔지니어에게는 이미 익숙한 이야기입니다. 1 << n은 2n이고, n비트로 표현할 수 있는 값의 개수도 2n입니다. 12비트 ADC는 212 = 4096단계, 비트 하나를 더하면 단계 수가 두 배가 됩니다. 비트 수는 더해서 늘지만 표현 범위는 곱해서 늘어납니다. 이것이 지수의 본질입니다.

지수의 계산 규칙은 "몇 번 곱했나"를 세어 보면 모두 당연해집니다.

규칙왜 그런가예
am · an = am+nm번 곱하고 또 n번 곱함210 · 210 = 220 (1 Ki × 1 Ki = 1 Mi)
(am)n = amnm번 곱한 묶음을 n번(103)2 = 106
a0 = 1한 번도 안 곱함. 곱셈의 시작값은 1prod = 1.0으로 시작하는 이유
a−n = 1/an음수 번 곱함 = 그만큼 나눔10−6 = 0.000001 (마이크로)
a1/2 = √a두 번 곱하면 a가 되는 수40.5 = 2

과학적 표기 3.3e−6은 3.3 × 10−6, 즉 3.3 μ입니다. 210 = 1024 ≈ 103이라는 사실도 기억해 두면 편합니다. 220 ≈ 백만, 230 ≈ 십억, 232 ≈ 43억(32비트 카운터의 한계)을 암산할 수 있습니다.

로그는 지수를 거꾸로 묻는다

지수가 "2를 10번 곱하면?"(답: 1024)이라면, 로그는 그 질문을 뒤집습니다. "2를 몇 번 곱하면 1024가 되나?"(답: 10)

log2 1024 = 10  ⇔  210 = 1024 loga x: "a를 몇 번 곱해야 x가 되나"

로그의 가장 유용한 성질은 곱셈을 덧셈으로 바꾼다는 것입니다. 지수의 첫 번째 규칙을 뒤집은 것입니다.

log(a · b) = log a + log b,   log(an) = n · log a

그래서 로그는 "몇 자리 수인가", "몇 비트가 필요한가", "몇 배인가"를 다룰 때 등장합니다.

  • 필요한 비트 수: 5000가지 값을 구분하려면 log2 5000 ≈ 12.3이므로 올림해서 13비트.
  • 자릿수: log10 1,000,000 = 6. 상용로그는 "10을 몇 번 곱했나", 즉 대략 자릿수입니다.
  • 이진 탐색 횟수: 100만 개 정렬 배열에서 찾기는 log2 106 ≈ 20번 비교면 충분합니다.

밑이 2인 로그(log2), 10인 로그(log10) 말고 밑이 e ≈ 2.718인 자연로그 ln도 자주 나옵니다. e가 왜 특별한지는 5장과 7장에서 미분과 함께 보게 됩니다. 지금은 "자연 현상의 성장·감쇠를 다룰 때 계산이 가장 깔끔해지는 밑"이라고만 알아 두세요.

데시벨: 엔지니어가 매일 쓰는 로그

앰프 이득, 필터 감쇠, 신호 대 잡음비(SNR)는 모두 "몇 배인가"라는 비율입니다. 비율은 수백만 배에서 백만분의 일까지 범위가 넓고, 여러 단을 거치면 곱해집니다. 로그를 취하면 범위가 다루기 쉬워지고 곱셈이 덧셈이 됩니다. 이것이 데시벨입니다.

전력비 [dB] = 10 · log10 P2P1,   진폭비 [dB] = 20 · log10 V2V1 전력은 전압의 제곱에 비례(P = V2/R)하므로 log(V2) = 2 log V, 그래서 10이 20이 된다

지수적 성장과 감쇠, 그리고 로그 그래프 위의 직선

"일정한 시간마다 두 배"가 되는 현상은 2t/T로 쓸 수 있고, T를 배증 시간이라고 합니다. 반대로 "일정한 시간마다 절반"이 되는 현상은 2−t/T, T는 반감기입니다. 커패시터 방전, 뜨거운 모터의 냉각, 신호가 매질을 지나며 약해지는 현상이 모두 이런 모양입니다.

지수 곡선을 세로축이 로그 눈금인 그래프에 그리면 직선이 됩니다. log(2t/T) = (t/T) · log 2이므로 t에 대한 1차식이기 때문입니다. 실험 데이터를 로그 그래프에 그려 직선이 나오면 "이건 지수 현상이구나" 하고 알아챌 수 있고, 그 기울기에서 반감기를 읽을 수 있습니다.

import math # Bits needed to tell N different values apart for n in (256, 4096, 5000, 1_000_000): print(f"{n:>9} levels -> log2 = {math.log2(n):6.2f} -> {math.ceil(math.log2(n))} bits") # Decibels: power uses 10*log10, amplitude uses 20*log10 def db_power(ratio): return 10 * math.log10(ratio) def db_amp(ratio): return 20 * math.log10(ratio) print(f"power x2 = {db_power(2):+.2f} dB, amplitude x2 = {db_amp(2):+.2f} dB") print(f"amplitude x0.1 = {db_amp(0.1):+.1f} dB") # A chain of stages: gains in dB simply add stages = {"amp": 20.0, "cable": -3.0, "filter": -1.0} total_db = sum(stages.values()) print(f"chain total = {total_db:+.1f} dB = x{10 ** (total_db / 10):.1f} in power") # Half-life: how long until a value decays to 1 % if it halves every 2 s? T_half = 2.0 t = T_half * math.log2(1 / 0.01) print(f"time to reach 1 % with half-life {T_half} s: {t:.2f} s") print("C/Python log() is the natural log:", round(math.log(math.e), 3), "| log10(1000) =", math.log10(1000))
흔한 함정
  • 10 log와 20 log 혼동: 전력(W, mW)이면 10, 전압·전류·진폭이면 20입니다. 헷갈리면 "전력은 진폭의 제곱"을 떠올리세요.
  • 0이나 음수의 로그: log 0은 −∞, 음수의 로그는 정의되지 않습니다. 신호 크기를 dB로 바꿀 때 log10(max(x, 1e-12))처럼 바닥값을 둡니다.
  • dB는 비율이다: "−40 dB"만으로는 절대 크기를 알 수 없습니다. 1 mW 기준이면 dBm, ADC 풀스케일 기준이면 dBFS처럼 기준을 밝혀야 절대값이 됩니다.
핵심 정리
  • 지수 = 몇 번 곱했나, 로그 = 몇 번 곱해야 하나. 서로 반대 질문이다.
  • 로그는 곱셈을 덧셈으로 바꾼다. 그래서 dB는 더하기만 하면 된다.
  • 전력비는 10 log10, 진폭비는 20 log10. 3 dB = 전력 2배, 6 dB = 진폭 2배.

다음 장에서는 또 하나의 기본 함수인 삼각함수를 다룹니다. 직각삼각형 공식으로 배웠던 기억은 잠시 내려놓고, 원 위를 도는 점으로 다시 보겠습니다. 모터, 바퀴, 교류, 로봇의 방향이 모두 그 그림 하나로 설명됩니다.
